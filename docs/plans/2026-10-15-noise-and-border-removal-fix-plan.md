## Review Focus

1. **Subsets.** A source product that is a spatial subset (`subset_offset_x/y ≠ 0`) must get exactly the noise of the same pixels in the full product. Pinned by Tasks A3, B2 and C3 (each has a subset-equivalence test).
2. **Tile boundaries.** Output must not depend on tiling: a 1-px tile overlap with a noise block, or a tile starting exactly on a burst or block edge. Pinned by Task B3 and the tile-size-invariance test in Task C3.
3. **Dual-pol and compact-pol products.** Each polarisation must use its own noise vector, never a fallback to another polarisation. Pinned by Tasks A2 and A3 (CH/CV and HH/HV fixtures).
4. **Already-processed inputs.** A product that is already denoised, already debursted, multilooked or map-projected must fail fast with a clear message rather than produce silently wrong numbers. Pinned by Tasks A3 and B4.
5. **Low-backscatter scenes (calm water).** Border masking must not erode valid water pixels into a granular mask, and thermal denoising must offer an unclipped output for later averaging. Pinned by Tasks B6 and C3.

```java
package eu.esa.sar.calibration.gpf.support;

/**
 * Per-pixel thermal-noise subtraction in the linear power domain.
 * Follows ESA MPC-0392 v2.3 section 6: a noise value of 0 means the noise is unknown (Eq-1);
 * negative results are optionally clipped (Eq-2), or kept for later averaging (Eq-3).
 */
public final class NoiseSubtraction {

    private NoiseSubtraction() {
    }

    /**
     * @param power power value (|DN|^2 or a calibrated backscatter coefficient)
     * @param noise noise in the same units; 0 = unknown; negative = re-introduce noise
     * @param clip  replace negative results by {@code floor}
     * @param floor value used for clipped pixels (0 for ESA Eq-2, 1e-5 for the historic SNAP behaviour)
     */
    public static double apply(final double power, final double noise, final boolean clip, final double floor) {
        if (noise == 0.0) {
            return power;
        }
        final double value = power - noise;
        return (clip && value < 0.0) ? floor : value;
    }
}
```

## Part A — `RCMRemoveThermalNoiseOp`

Defects being fixed:
1. The `q` band is written as a scaled `i` value.
2. The noise LUT index double-counts `x0`.
3. NESZ (calibrated units) is subtracted from uncalibrated DN².
4. The last of the Beta/Sigma/Gamma vectors parsed wins.
5. The reader names every `noiseLevels_<POL>.xml` element `noiseLevels`, so the polarisation is lost.
6. Amplitude bands get power values but keep the Amplitude unit.
7. `noiseSubtractionPerformed` is ignored.
8. Negative `stepSize` is not handled.
9. ScanSAR per-beam vectors and azimuth scaling are ignored.

Background facts (verified on `E:\TestData\s1tbx\SAR\RCM\EODMS\GRD\RCM1_OK1024567_PK1025865_1_SC50MA_20191205_225938_HH_HV_GRD`):
- **Per-polarisation files.** `metadata/calibration/noiseLevels_<POL>.xml` has 3× `referenceNoiseLevel` (Beta Nought, Sigma Nought, Gamma), plus `perBeamReferenceNoiseLevel` (beam, Beta Nought) and `azimuthNoiseLevelScaling` (beam, stepSize, `noiseLevelScalingValues` in dB, centred about the burst middle) for ScanSAR.
- **Trust Beta Nought.** The schema says the Beta Nought vector is the reference. In this product the Sigma Nought vector reads about −88 dB against −28 dB for Beta Nought, so the Sigma/Gamma vectors are not trusted. σ⁰ and γ⁰ noise are derived from β⁰ using the incidence angle.
- **Burst map.** `product.xml` → `grdBurstMap/burstAttributes` (attribute `beam`, fields `topLeftLine`, `topLeftPixel`, `bottomRightLine`, `bottomRightPixel`).
- **Noise flag.** `product.xml` → `imageGenerationParameters/sarProcessingInformation/noiseSubtractionPerformed`.
- **Calibration convention.** `RCMCalibrator` (rstb-op-calibration) uses σ⁰ = (DN² + offset)/A for GRD and DN²/A² for SLC. Noise in DN² is therefore NEβ·A_β for GRD and NEβ·A_β² for SLC.
- **XML → metadata mapping.** `AbstractMetadataIO.AddXMLMetadata` turns a leaf *with* XML attributes (e.g. `<noiseLevelValues units="dB">…`) into a child element holding attributes `noiseLevelValues` and `units`. A leaf *without* attributes becomes an attribute on its parent.

```java
package eu.esa.sar.calibration.gpf.support;

import org.esa.snap.core.datamodel.MetadataElement;

import java.util.ArrayList;
import java.util.HashMap;
import java.util.List;
import java.util.Map;

/**
 * RCM thermal-noise model from noiseLevels_POL.xml (schema rcm_prod_noiseLevels.xsd).
 * The Beta Nought vectors are the reference; sigma/gamma noise are derived by the caller via
 * the incidence angle. ScanSAR: per-beam range vectors selected through grdBurstMap and
 * multiplied by the per-beam azimuth scaling, centred on the burst middle line.
 */
public final class RCMNoiseModel {

    public static final class Vector {
        private final int first;
        private final int step;
        private final double[] values;

        public Vector(final int first, final int step, final double[] values) {
            if (step == 0 || values.length == 0) {
                throw new IllegalArgumentException("invalid noise vector");
            }
            this.first = first;
            this.step = step;
            this.values = values;
        }

        /** Linear interpolation at a pixel/line position, clamped to the vector ends. */
        public double valueAt(final double pos) {
            if (values.length == 1) {
                return values[0];
            }
            final double t = (pos - first) / step;
            if (t <= 0) {
                return values[0];
            }
            if (t >= values.length - 1) {
                return values[values.length - 1];
            }
            final int i = (int) t;
            final double mu = t - i;
            return values[i] + mu * (values[i + 1] - values[i]);
        }
    }

    private static final class Burst {
        final String beam;
        final int top, left, bottom, right;

        Burst(String beam, int top, int left, int bottom, int right) {
            this.beam = beam;
            this.top = top;
            this.left = left;
            this.bottom = bottom;
            this.right = right;
        }

        boolean contains(int x, int y) {
            return x >= left && x <= right && y >= top && y <= bottom;
        }
    }

    private final Vector reference;
    private final Map<String, Vector> perBeam;
    private final Map<String, double[]> azimuthScaling;  // linear, index centred on burst middle
    private final Map<String, Integer> azimuthStep;
    private final List<Burst> bursts;
    private final Vector gain;
    private final boolean isSLC;

    private RCMNoiseModel(Vector reference, Map<String, Vector> perBeam, Map<String, double[]> azimuthScaling,
                          Map<String, Integer> azimuthStep, List<Burst> bursts, Vector gain, boolean isSLC) {
        this.reference = reference;
        this.perBeam = perBeam;
        this.azimuthScaling = azimuthScaling;
        this.azimuthStep = azimuthStep;
        this.bursts = bursts;
        this.gain = gain;
        this.isSLC = isSLC;
    }

    public static RCMNoiseModel parse(final MetadataElement noiseLevels, final MetadataElement lutBeta,
                                      final MetadataElement grdBurstMap, final boolean isSLC) {
        Vector reference = null;
        final Map<String, Vector> perBeam = new HashMap<>();
        final Map<String, double[]> azScaling = new HashMap<>();
        final Map<String, Integer> azStep = new HashMap<>();

        for (MetadataElement e : noiseLevels.getElements()) {
            final String name = e.getName();
            if (name.equals("referenceNoiseLevel") && isBeta(e)) {
                reference = readVector(e, "pixelFirstNoiseValue", "noiseLevelValues");
            } else if (name.equals("perBeamReferenceNoiseLevel") && isBeta(e)) {
                perBeam.put(e.getAttributeString("beam"), readVector(e, "pixelFirstNoiseValue", "noiseLevelValues"));
            } else if (name.equals("azimuthNoiseLevelScaling")) {
                final double[] dB = parseValues(e, "noiseLevelScalingValues");
                final double[] lin = new double[dB.length];
                for (int i = 0; i < dB.length; i++) {
                    lin[i] = Math.pow(10.0, dB[i] / 10.0);
                }
                azScaling.put(e.getAttributeString("beam"), lin);
                azStep.put(e.getAttributeString("beam"), Integer.parseInt(e.getAttributeString("stepSize")));
            }
        }
        if (reference == null && perBeam.isEmpty()) {
            throw new IllegalArgumentException("RCM noise levels contain no Beta Nought vector");
        }

        final List<Burst> bursts = new ArrayList<>();
        if (grdBurstMap != null) {
            for (MetadataElement b : grdBurstMap.getElements()) {
                if (b.getName().equals("burstAttributes")) {
                    bursts.add(new Burst(b.getAttributeString("beam"),
                            b.getAttributeInt("topLeftLine"), b.getAttributeInt("topLeftPixel"),
                            b.getAttributeInt("bottomRightLine"), b.getAttributeInt("bottomRightPixel")));
                }
            }
        }

        final double[] gains = parseNumbers(lutBeta.getAttributeString("gains"));
        final Vector gain = new Vector(Integer.parseInt(lutBeta.getAttributeString("pixelFirstLutValue")),
                Integer.parseInt(lutBeta.getAttributeString("stepSize")), gains);

        return new RCMNoiseModel(reference, perBeam, azScaling, azStep, bursts, gain, isSLC);
    }

    /** Linear beta-nought noise at full-image pixel (x, y). */
    public double betaNoise(final int x, final int y) {
        Burst burst = null;
        for (Burst b : bursts) {
            if (b.contains(x, y)) {
                burst = b;
                break;
            }
        }
        if (burst == null) {
            return reference != null ? reference.valueAt(x) : 0.0;   // 0 = unknown
        }
        final Vector range = perBeam.getOrDefault(burst.beam, reference);
        double n = range != null ? range.valueAt(x) : 0.0;
        final double[] scale = azimuthScaling.get(burst.beam);
        if (scale != null && n != 0.0) {
            final int centreLine = (burst.top + burst.bottom) / 2;
            final int step = azimuthStep.get(burst.beam);
            final double idx = (scale.length - 1) / 2.0 + (double) (y - centreLine) / step;
            n *= new Vector(0, 1, scale).valueAt(idx);
        }
        return n;
    }

    /** Noise in |DN|^2 units, matching RCMCalibrator (GRD: beta = DN^2/A, SLC: beta = DN^2/A^2). */
    public double noiseDN2(final int x, final int y) {
        final double a = gain.valueAt(x);
        return betaNoise(x, y) * (isSLC ? a * a : a);
    }

    private static boolean isBeta(MetadataElement e) {
        return "Beta Nought".equalsIgnoreCase(e.getAttributeString("sarCalibrationType", ""));
    }

    private static Vector readVector(MetadataElement e, String firstAttr, String valuesName) {
        final double[] dB = parseValues(e, valuesName);
        final double[] lin = new double[dB.length];
        for (int i = 0; i < dB.length; i++) {
            lin[i] = Math.pow(10.0, dB[i] / 10.0);
        }
        return new Vector(Integer.parseInt(e.getAttributeString(firstAttr)),
                Integer.parseInt(e.getAttributeString("stepSize")), lin);
    }

    /** Values are either a child element (leaf with units attribute) or a plain attribute. */
    private static double[] parseValues(MetadataElement e, String name) {
        final MetadataElement child = e.getElement(name);
        final String s = child != null ? child.getAttributeString(name) : e.getAttributeString(name);
        return parseNumbers(s);
    }

    private static double[] parseNumbers(String s) {
        final String[] tok = s.trim().split("\\s+");
        final double[] v = new double[tok.length];
        for (int i = 0; i < tok.length; i++) {
            v[i] = Double.parseDouble(tok[i]);
        }
        return v;
    }
}
```

## Part C — `RemoveGRDBorderNoiseOp`

### What the sources say

**ESA MPC-0243 v2.2:**
- **IPF ≥ 2.90:** no-value pixels are set to 0 by the IPF; no masking is needed.
- **IPF < 2.90 method, per line:**
  1. On the co-pol channel, take the first 2000 samples.
  2. Interpolate the middle noise vector over them.
  3. Denoise with clipping, `sqrt(max(DN² − η, 0))`.
  4. Walk inward from the edge while the value is below 0.5, and mask `[0, trimNear]`.
  5. Apply the same mask to cross-pol.

  The mask is **contiguous from the edge**. The note says the effect appears at near range only, and that the method fails over calm water.

**Current SNAP operator deviations:**
- Each pixel is tested on its own, so masks have holes and form a granular pattern over the sea.
- An extra `DN < 30` per-pixel rule (not in v2.2) masks low-backscatter water.
- The search strip is `borderLimit = 500`.
- The border position comes from a scene-mean derivative peak, with a `max/mean > 10` test and a `*0.8` fudge on the right side.
- A `System.out.println` is left in.

**Measured failure rates:**
- Ali et al. 2018: the SNAP operator fails on 69% of 500 scenes. Their bidirectional all-samples method (Alg. 3) failed on 0 of 1500.
- Stasolla & Neyt 2018: SNAP's kappa is 0.91 (commission 5.83%, SM commission 53%); their morphological method reaches kappa 0.98.

**Other implementations:**
- pyroSAR (`method='pyroSAR'`): the ESA mask followed by a per-edge polyline boundary, which un-masks interior water.
- The SNAP SNAP-3577 fix: products from IPF ≥ 2.90 are passed through.
- GEE and S1 NRB both run border removal on raw DN, before thermal noise removal and calibration.

**Design:**
- **Two detection methods, both producing a per-line cut.**
  - `ESA` follows MPC-0243 exactly: a contiguous run of denoised amplitude below `trimThreshold`. It needs a noise LUT and is only valid for IPF < 2.90 IW/EW.
  - `Bidirectional` follows Ali et al. Alg. 3: the first strong jump in the smoothed raw-DN difference profile. It needs no annotation, so it also works for SM.
- **A shared regulariser on the cut series:** median filter along the edge (window 51), split into at most 3 steps, take the 99.8th percentile per step, add 1, set it to 0 if ≤ 2, otherwise add a 5-px buffer. This removes the gaps and granularity, and interior water is never masked because only `[edge, cut)` is masked.
- **All four sides**, with the top and bottom handled via columns.
- **Default by product:**
  - IPF ≥ 2.90 IW/EW: pass-through (ESA guidance).
  - SM: `Bidirectional` (IPF 2.90 did not fix SM).
  - IPF < 2.90 IW/EW: `ESA` + regulariser.
- **Placement:** border removal stays on raw DN (the validator already enforces uncalibrated input). The help page states the order Apply-Orbit → Border Noise → Thermal Noise → Calibration.

```java
import java.util.List;

/**
 * Per-line border-noise cut estimation for Sentinel-1 GRD.
 * esaCut: ESA MPC-0243 v2.2 section 5.5 (contiguous run from the edge).
 * jumpCut + regularise: Ali et al. 2018, IEEE J-STARS 11(3), Algorithm 3 (bidirectional all-samples).
 */
public final class BorderCutDetector {

    private BorderCutDetector() {
    }

    public static int esaCut(final double[] amplitude, final double[] noisePower, final double trimThreshold) {
        int n = 0;
        while (n < amplitude.length) {
            final double a = amplitude[n];
            final double d = Math.sqrt(Math.max(a * a - noisePower[n], 0.0));
            if (!(d < trimThreshold)) {         // NaN counts as border
                break;
            }
            n++;
        }
        return n;
    }

    public static int jumpCut(final double[] a, final double jumpThreshold, final double validEdgeThreshold) {
        if (a.length < 3 || a[0] > validEdgeThreshold) {
            return 0;
        }
        for (int i = 0; i + 2 < a.length; i++) {
            final double m = ((a[i + 2] - a[i + 1]) + (a[i + 1] - a[i])) / 2.0;
            if (m > jumpThreshold) {
                return i + 1;
            }
        }
        return 0;
    }

    public static int[] regularise(final int[] cuts, final int medianWindow, final int maxSteps, final int minStep,
                                   final double percentile, final int buffer) {
        final int n = cuts.length;
        final int[] med = medianFilter(cuts, medianWindow);

        // segment boundaries at the maxSteps largest unique jumps larger than minStep
        final List<Integer> bounds = new ArrayList<>();
        bounds.add(0);
        final Integer[] order = new Integer[Math.max(n - 1, 0)];
        for (int i = 0; i < order.length; i++) order[i] = i;
        Arrays.sort(order, (p, q) -> Integer.compare(Math.abs(med[q + 1] - med[q]), Math.abs(med[p + 1] - med[p])));
        for (int k = 0; k < Math.min(maxSteps, order.length); k++) {
            final int i = order[k];
            if (Math.abs(med[i + 1] - med[i]) > minStep) {
                bounds.add(i + 1);
            }
        }
        bounds.add(n);
        bounds.sort(Integer::compare);

        final int[] out = new int[n];
        for (int s = 0; s + 1 < bounds.size(); s++) {
            final int from = bounds.get(s), to = bounds.get(s + 1);
            if (from >= to) continue;
            int w = (int) Math.round(percentileOf(med, from, to, percentile)) + 1;
            w = (w <= 2) ? 0 : w + buffer;
            Arrays.fill(out, from, to, w);
        }
        return out;
    }

    private static int[] medianFilter(final int[] v, final int window) {
        final int half = window / 2;
        final int[] out = new int[v.length];
        final int[] buf = new int[window];
        for (int i = 0; i < v.length; i++) {
            int m = 0;
            for (int j = Math.max(0, i - half); j <= Math.min(v.length - 1, i + half); j++) buf[m++] = v[j];
            Arrays.sort(buf, 0, m);
            out[i] = buf[m / 2];
        }
        return out;
    }

    private static double percentileOf(final int[] v, final int from, final int to, final double p) {
        final int[] s = Arrays.copyOfRange(v, from, to);
        Arrays.sort(s);
        final double rank = p / 100.0 * (s.length - 1);
        final int lo = (int) Math.floor(rank), hi = (int) Math.ceil(rank);
        return s[lo] + (rank - lo) * (s[hi] - s[lo]);
    }
}
```

`medianFilter` as written is O(n·w·log w). With n of about 25k lines and w = 51 that is fine (well under 1 s). Do not optimise it.

- **Detection (a synchronized lazy prepass, as today):**

```java
    private synchronized void detectBorders() {
        if (borderDetected) return;
        final int w = sourceImageWidth, h = sourceImageHeight, depth = Math.min(borderLimit, Math.min(w, h) / 2);
        leftCut = regulariseSide(rawCuts(Side.LEFT, depth, h));
```
