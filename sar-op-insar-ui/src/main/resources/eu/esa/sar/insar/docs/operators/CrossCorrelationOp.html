Cross Correlation

Cross Correlation Operator

The Cross Correlation operator is a component of coregistration. Image co-registration is an essential step for Interferometry SAR (InSAR) imaging. It aligns one or more secondary images with a reference image in such a way that the each pixel from the co-registered secondary image represents the same point on the Earth surface as its corresponding pixel in the reference image.

The co-registration is accomplished through two major processing steps: Cross Correlation and WARP. In GCP selection, a set of uniformly spaced Ground Control Points (GCPs) in the reference image are generated first, then their corresponding GCPs in the secondary image are computed. In WARP processing step, these GCP pairs are used to construct a WARP distortion function, which establishes a map between pixels in the reference and secondary images. With the WARP function computed, the co-registered image is generated by mapping the secondary image pixels onto reference image.

This operator computes secondary GCPs by coarse registration, and for complex input also by fine registration:
  • Detected input (amplitude or intensity): only coarse registration runs. The shift is the peak of the upsampled cross-correlation, so it is quantised to 1/(Row or Column Interpolation Factor) of a pixel: 0.5 pixel with the default factor 2.
  • Complex input (i/q bands): coarse registration is followed by the fine step described below when "Apply Fine Registration" is on (the default). Switch it off to coregister on amplitude alone, for example for temporally decorrelated pairs where the fine step rejects most GCPs.
The Coregistration graph in the menu sets both interpolation factors to 4 and GCP Tolerance to 0.25.

Coarse Registration

   The coarse registration is achieved using a cross correlation operation between the images on a series of imagettes defined across the images. The major processing steps are listed as the follows:
  1. For a given reference GCP, find initial secondary GCP using geographical position information of GCP.
  2. Determine the imagettes surrounding the reference and secondary GCPs using user selected coarse registration window size.
  3. Compute new secondary GCP position by performing cross-correlation of the reference and secondary imagettes.
  4. If the row or column shift of the new secondary GCP from the previous position is no less than user selected GCP tolerance and the maximum number of iteration is not reached, then move the secondary imagette to the new GCP position and go back to step 3. Otherwise, save the new secondary GCP and stop.
   Those GCPs, for which the maximum number of iterations has been reached or its final GCP shift is still greater than the tolerance, are eliminated as invalid GCPs.

Fine Registration

  For complex input the fine step refines each coarse GCP. Its steps are:
  1. Take complex imagettes of Fine Registration Window Width x Height around the reference GCP and the coarse secondary GCP.
  2. Convert both to amplitude and subtract the mean of each. The interferometric phase is not used, so this is an incoherent (amplitude) match.
  3. Compute the normalised cross-correlation (NCC) of the two amplitude imagettes with an FFT. Around its peak, a region set by the Search Window Accuracy in azimuth and range is oversampled by the Window oversampling factor; the oversampled peak gives the sub-pixel shift.
  4. Drop the GCP if the peak NCC is below the Coherence Threshold.
   "Coherence Threshold" therefore thresholds an amplitude NCC between the imagettes, not the interferometric coherence. Over temporally decorrelated scenes (for example cropland between acquisitions weeks apart) this NCC is often 0.1–0.3, so with the default threshold of 0.6 almost every GCP is rejected and Warp stops with "not enough valid GCPs". Lower the threshold or switch off "Apply Fine Registration".

Coherence maximisation

  With "Optimize for InSAR" switched off, the fine step instead searches the sub-pixel shift that maximises the coherence, with Powell's method [1], using Coherence Window Size and "Use coherence sliding window". These two options have no effect while "Optimize for InSAR" is on (the default).

Parameters Used

   The parameters used by the Operator are as follows:
  1. Number of GCPs: The total number of GCPs used for the co-registration.
  2. Coarse Registration Window Width: The window width for cross-correlation in coarse GCP selection. It must be power of 2.
  3. Coarse Registration Window Height: The window height for cross-correlation in coarse GCP selection. It must be power of 2.
  4. Row Interpolation Factor: The row upsampling factor used in cross correlation operation. It must be power of 2.
  5. Column Interpolation Factor: The column upsampling factor used in cross correlation operation. It must be power of 2.
  6. Max Iterations: The maximum number of iterations for computing coarse secondary GCP position.
  7. GCP Tolerance: The stopping criterion for secondary GCP selection.
  8. Apply Fine Registration: refine each coarse GCP by fine registration (complex input only; default on). Detected input has no fine step.
  9. Optimize for InSAR: fine registration by oversampled amplitude cross-correlation (on, the default) or by coherence maximisation (off).
  10. Coherence Window Size: used only when "Optimize for InSAR" is off (see Coherence maximisation).
  11. Coherence Threshold: GCPs whose fine-step amplitude NCC is below this threshold are dropped.
  12. Fine Registration Window Width: The window width of the fine amplitude correlation. It must be power of 2.
  13. Fine Registration Window Height: The window height of the fine amplitude correlation. It must be power of 2.
  14. Use coherence sliding window: used only when "Optimize for InSAR" is off (see Coherence maximisation).
