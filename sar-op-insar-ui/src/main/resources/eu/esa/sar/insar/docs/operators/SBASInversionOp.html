SBAS Inversion

SBAS Inversion Operator

The SBAS Inversion operator inverts a stack of unwrapped small-baseline interferograms for per-epoch phase, displacement, and a linear velocity, following Berardino, Fornaro, Lanari & Sansosti (IEEE TGRS 2002).

Per pixel it builds the design matrix A of size M× (N-1) from the network of pairs, drops equations whose coherence is below the threshold, and solves the weighted normal equations x = (ATWA)-1 ATWφ. Tikhonov regularisation activates automatically when the matrix is ill-conditioned. Per-epoch phase is then converted to LOS displacement (d = −λ / 4π · φ) and fit to a linear-in-time model for velocity (an unweighted least-squares fit of the per-epoch values).

Input

  • A multi-temporal stack containing, per pair k:
    • Unwrapped phase band with unit phase or abs_phase and "unw" (any case) in its name, e.g. Unw_Phase_ifg_<ref-date>_<sec-date> or UnwPhase_ifg_<swath>_<POL>_<ref-date>_<sec-date> as written by Batch Snaphu Unwrap or Snaphu Import. Bands without a unit are skipped.
    • Coherence band with the same two dates, unit coherence or a name starting with coh_, e.g. coh_<swath>_<POL>_<ref-date>_<sec-date>.
  • Acquisition dates are extracted as the last two ddMMMyyyy tokens in each band name. Pairs are keyed by these two dates only, so use one polarisation and one sub-swath per product; with several, the last band per date pair is used.

Route to an SBAS-ready product: run Snaphu Export on the multi-pair interferogram product, then Batch Snaphu Unwrap on the same product with the folder Snaphu Export created. Batch Snaphu Unwrap replaces each wrapped phase band with an UnwPhase_ifg_<tag> band (unit abs_phase) and passes the coh_* bands through, so SBAS Inversion reads its output directly. If you run SNAPHU outside SNAP instead, import the results with Snaphu Import, each time with the previous import (at first the interferogram product) as the first input, leaving Do NOT save Wrapped interferogram unticked. Phase Linking (step 1) is optional — SBAS works on plain pairwise unwrapped interferograms too.

Output

  • phase_<date> — per-epoch unwrapped phase relative to the reference epoch (rad).
  • displacement_<date> — LOS displacement (mm).
  • velocity — unweighted least-squares linear fit of the per-epoch phases (mm/year).
  • velocity_uncertainty — 1-sigma velocity (mm/year).
  • temporal_coherence — residual-based quality, [0, 1].
  • residual_<m>_<s> — per-pair residual (optional). Named and signed in date order (earlier date first), also for a pair whose input band lists the later date first.
  • closure_phase_rms — RMS triplet closure phase (on by default). Each closure is wrapped to (−π, π] before the RMS, so the band shows sub-cycle phase inconsistency (for example from soil moisture or vegetation change). It does not reveal whole-cycle (2π) unwrapping errors. Only triplets whose three pairs are all above the coherence threshold are used; where there is none (for example everywhere in a sequential network) the band is no-data (NaN).

Either date may come first in a pair band name: SBAS Inversion orders the epochs by date and negates the phase of a pair named later date first.

Changed in SNAP 15: earlier versions did not negate later-date-first pairs, so stacks containing such pairs gave wrong per-epoch results, and closure_phase_rms was 0 instead of no-data where no triplet exists.

Displacement is relative to the reference epoch, not to a reference point: subtract a stable area yourself (see From Phase to Displacement).

Prerequisites

  • Unwrapped interferogram bands with 'unw' in the name, ending in <ref-date>_<sec-date> (ddMMMyyyy), unit phase or abs_phase, covering at least 3 unique epochs
  • From Batch Snaphu Unwrap: run Snaphu Import first (interferogram product first, Batch result second); it sets the unit and brings back the coherence bands
  • A coherence band for every pair, unit coherence or name starting 'coh_': a pair without one fails at compute time
