Split Stack into Multiple References

This menu item runs a graph with the operator MultiMasterStackGenerator. It takes a single coregistered SLC stack (one reference acquisition and N−1 secondary acquisitions, as produced by Coregistration or DEM-Assisted Coregistration) and splits it into N−1 two-date pair products, one for each pair of consecutive acquisition dates (A-B, B-C, C-D, ...). This gives a simple chain of short-time-span pairs, for example for small-baseline (SBAS) processing in external tools such as PyRate.

Input

A coregistered SLC stack with a single reference and at least two secondaries, with the standard stack band naming (i_/q_ bands tagged with the reference (_mst or _ref) or with the secondary acquisition date).

Parameters

  • Output folder (outputFolder): the folder the pair products are written to. It is required: there is no separate Write step. In the dialog it is a folder chooser labelled Output folder, set to your home folder when the dialog opens. In GPT or a graph XML, an empty value stops the run with the error Output folder must be set. A folder that does not exist yet is created. A path that is an existing file, or a folder that cannot be created or written to, stops the run with an error. If writing a pair product fails, the run fails with that error instead of finishing without output.

Output

  • The acquisitions are sorted by acquisition date (first_line_time). For each pair of consecutive dates, one BEAM-DIMAP product is written to the output folder, named <product type>_<yyyyMMdd>_<yyyyMMdd>.
  • In each pair product the earlier date is the Reference and the later date is the Secondary. The band names are re-tagged to match (_ref for the earlier date, _sec for the later date).
  • The metadata of both dates is stored under Secondary_Metadata, and Abstracted_Metadata gets the flag multireference_split. Interferogram Formation recognises this flag and takes the first entry of Secondary_Metadata (the earlier date) as the Reference of the pair. The rest of Abstracted_Metadata is copied unchanged from the reference of the original stack.
  • With N acquisitions you get N−1 products. Other pairs (for example A-C) are not written.

Typical workflow

  1. Coregister all SLCs into one stack (e.g. DEM-Assisted Coregistration or the TOPS Back-Geocoding + Enhanced Spectral Diversity chain).
  2. Run Split stack into multiple references on that coregistered stack.
  3. Process each pair product separately: Interferogram Formation, then any further steps (TOPS Deburst, Goldstein phase filtering, subset, SNAPHU export and unwrapping, terrain correction).
  4. Combine the results downstream, e.g. by small-baseline network inversion in an external tool such as PyRate after export.

Notes

  • This operator does not re-coregister: the underlying samples are the same as in the input stack. Only the reference / secondary roles are reassigned.
  • If the input stack was coregistered with non-trivial enhanced spectral diversity (ESD) residual offsets that depended on the original reference, those offsets are baked in; re-running ESD against the new reference will give residuals close to zero only if the original ESD converged.
