Phase Linking (DS InSAR)

Phase Linking Operator

The Phase Linking operator performs Distributed-Scatterer (DS) InSAR phase estimation over a coregistered SLC stack. For every output pixel it selects a set of Statistically Homogeneous Pixels (SHPs), forms the N×N complex sample covariance over that set, normalises it to a coherence matrix T, and estimates the per-epoch phasor vector that best explains all N(N−1)/2 pairwise phases jointly.

The output is a stack of phase-linked SLC bands — same amplitude as the input, but with phase replaced by the optimal estimate. The resulting stack is a drop-in input to the existing Interferogram / Coherence / Multi-Reference InSAR operators; downstream pairs show much higher coherence over distributed scatterers (vegetation, debris, farmland) than the raw pairwise interferograms.

Input

  • A coregistered SLC stack — output of Back Geocoding + Enhanced Spectral Diversity for TOPS, or Coregistration for Stripmap.
  • Burst-organised TOPS input is not accepted — run TOPSAR-Deburst first.

Phase Linking only modifies phase — amplitudes are preserved — so the downstream graph is identical to a regular pairwise-InSAR graph. Skip Phase Linking entirely if you only care about PS-style point targets; the gain is over distributed scatterers (vegetation, debris, soil) where pixel-wise speckle dominates.

Output

  • i_pl_<swath>_<POL>_ref_<date> / q_pl_<swath>_<POL>_ref_<date> for the Reference epoch and i_pl_<swath>_<POL>_sec<k>_<date> / q_pl_<swath>_<POL>_sec<k>_<date> for each Secondary — one complex pair per epoch with the phase-linked phase. The swath and polarisation parts are left out when the input has none.
  • tempCoh_<POL> (optional, default on) — Pepe-Lanari goodness-of-fit temporal coherence per pixel, range [0, 1]; NaN (no-data) where the pixel had too few SHPs. Named tempCoh when the input has no polarisation.
  • numSHP_<POL> (optional, default off) — count of SHP neighbours used per pixel; 0 is no-data. Named numSHP when the input has no polarisation.

Pixels are passed through (the output keeps the original SLC samples) in two cases: when fewer than max(Minimum SHPs, N) SHPs are found (tempCoh is then no-data), and when the temporal coherence is below the Temp. Coherence Threshold (tempCoh then still records the value). Not every pixel of the output is therefore phase-linked; mask on tempCoh if you need to know.

Parameters

ParameterDefaultNotes
Window Azimuth21 SHP search window height in pixels (forced odd).
Window Range7 SHP search window width in pixels (forced odd). On Sentinel-1 IW the default 21 az × 7 rg covers about 290 m × 26 m on the ground, a long azimuth strip; Phase Linking in Depth advises 7 az × 21 rg (about 100 m × 80 m, same pixel count).
SHP TestKS Two-sample amplitude test: KS (Kolmogorov-Smirnov, default, SqueeSAR / FRInGE), AD (Anderson-Darling), TLog (Welch t-test on log-amplitude, MiaplPy fast mode).
SHP alpha0.05 Significance level for the SHP test.
Minimum SHPs20 Below this count the pixel is passed through unchanged. The effective minimum is raised to the stack size N when smaller, so the N×N covariance stays full rank (a rank-deficient covariance cannot be phase-linked, especially by EMI, which inverts it).
EstimatorEVD EVD: dominant eigenvector of T (Fornaro et al. 2015; Cao, Lee, Jung 2015). EMI: lower-bias variant — smallest-eigenvalue eigenvector of Γ−1 ⊙ T, where Γ = |T| and Γ−1 is its matrix inverse (Ansari, De Zan, Bamler 2018).
Reference Epochmedian epoch ddMMMyyyy. Empty → chronological median. The reference epoch is the zero-phase datum; its band is written real-valued (only relative phases matter downstream).
Temp. Coherence Threshold0.6 Pixels whose temporal coherence is below this are not masked: they are passed through with their original SLC samples, and tempCoh records the value.
Coherence Magnitude Bias Correctionoff Removes the positive bias of the sample coherence magnitude (first-order number-of-looks correction). Beneficial with the EVD estimator; may degrade EMI at low coherence, so it is off by default.

v1 Scope and Limitations

  • Single-shot full-stack EVD/EMI. Recommended operating range is N ≤ ~50 epochs. For longer stacks consider subsampling, or wait for the v2 ministack / sequential mode.
  • No iterative MLE refinement (planned for v2).
  • TOPS bursts must be merged upstream (TOPSAR-Deburst).
