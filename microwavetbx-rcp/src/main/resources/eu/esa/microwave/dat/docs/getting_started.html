Microwave Toolbox: Getting Started

The Microwave Toolbox adds SAR processing to SNAP: readers for SAR missions, calibration, speckle filtering, terrain correction, interferometry, polarimetry and ocean and land applications. This page shows where to start reading and which page answers which task.

A learning path

  1. Concepts. Short pages that explain the physics behind the tools. Start with SAR Fundamentals, SAR Geometry, Radiometry and Calibration and Speckle and Multilooking. For phase-based work continue with InSAR Fundamentals; for multi-channel data with the Polarimetry Primer.
  2. Workflows. Step-by-step processing chains from raw product to result, with the operators in order and the settings that matter (table below).
  3. Operators. Every operator has its own help page with its parameters and output bands. Open it with the Help button of the operator dialog. Each page links back to the concepts it depends on.
  4. Readers. One page per mission or format describes the products that can be opened and how they are read (see Readers below).

Unfamiliar terms are defined in the SAR Glossary.

First steps with Sentinel-1

Open a Sentinel-1 product with File > Open Product, selecting either the downloaded .zip or the manifest.safe file of the unpacked .SAFE folder. In the Product Explorer, the Metadata node holds the Abstracted Metadata, the sensor-independent summary (pass direction, radar frequency, pixel spacing, incidence angles) that all operators read. Then decide on the product level. A GRD product has no phase and is the starting point for backscatter maps and change detection: apply Radar > Apply Orbit File, Remove GRD Border Noise (Radar > Sentinel-1 TOPS), thermal noise removal and calibration from Radar > Radiometric, and terrain correction from Radar > Geometric > Terrain Correction, as described in the GRD workflow. An IW SLC product keeps the phase and is organised in sub-swaths and bursts; it is processed with the tools under Radar > Sentinel-1 TOPS (see Sentinel-1 TOPS and the Sentinel-1 DInSAR workflow). Every operator can also be chained in the Graph Builder or run from the command line with gpt; gpt Terrain-Correction -h lists the parameters of one operator.

Readers

Each reader page lists the supported product types and modes:

  • Sentinel-1
  • RADARSAT-2 and RADARSAT Constellation Mission
  • TerraSAR-X, COSMO-SkyMed, ALOS-2
  • NISAR, BIOMASS
  • ICEYE, Capella
  • ENVISAT ASAR, ERS-1/2

All readers are listed on the Supported Missions page.
