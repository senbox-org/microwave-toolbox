SAR Workflows: InSAR DEM Generation

InSAR DEM Generation

An interferogram whose topographic phase is kept, unwrapped and scaled by the baseline geometry gives terrain height. This chain produces an elevation band in metres, geocoded at the end. Input: two SLC products with a useful perpendicular baseline and a short time between them.

Choosing the pair

Height sensitivity is set by the height of ambiguity, the height difference that gives one fringe:

h2π = λ R sinθ / (2 B⊥)

where λ is the wavelength, R the slant range, θ the incidence angle and B⊥ the perpendicular baseline. The height error scales with it: σh ≈ h2π σφ / (2π), with σφ the phase noise in radians. For Sentinel-1 IW, B⊥ = 150 m gives h2π ≈ 100 m. Trade-offs:

  • Larger B⊥: more precise heights, but denser fringes, more geometric decorrelation and harder unwrapping in steep terrain.
  • Temporal baseline: keep it short; deformation and atmosphere also enter the phase. One fringe of atmospheric delay (λ/2) becomes a height error of h2π, so pick dry, stable dates and the shortest interval available.
  • Land cover: bare and sparsely vegetated terrain keeps coherence; forest and snow do not.

List the baselines of your candidate dates with Radar > Interferometric > InSAR Stack Overview.

Before you start

  • Orbits and DEM: precise orbits where available. A reference DEM (Copernicus 30 m by default) is used for coregistration and by the default Phase to Elevation method, and is your benchmark for checking the result.
  • Ready-made graphs (Graph Builder, Graphs > Radar > InSAR Graphs): DEM-Generation-Pre-Processing and DEM-Generation-Pre-Processing-Snaphu. They run Apply Orbit File, Create Stack, Cross-Correlation, Warp, Interferogram and Goldstein filtering, with no topographic phase removal; the SNAPHU variant exports with cost mode TOPO. They are stripmap graphs; for Sentinel-1 IW, coregister with the TOPS chain instead.

Steps

  1. Coregister the pair: for stripmap, Apply Orbit File and Coregistration or DEM Assisted Coregistration (see the stripmap workflow); for Sentinel-1 IW, TOPS Split, Apply Orbit File, Back Geocoding and ESD (see the Sentinel-1 workflow).
  2. Interferogram Formation (Interferogram; help). Keep Subtract flat-earth phase on and Subtract topographic phase off (both defaults). Do not run Topographic Phase Removal: the topographic phase is the signal. For IW, run S-1 TOPS Deburst afterwards.
  3. Multilooking (Multilook; help). The look numbers set the posting of the DEM. With a small h2π keep the looks low so that fringes on steep slopes are not aliased.
  4. Goldstein Phase Filtering (GoldsteinPhaseFiltering; help), adaptive alpha on (default).
  5. Snaphu Export (SnaphuExport; help): set Statistical-cost mode to TOPO; the default is DEFO. Run SNAPHU, then Snaphu Import.
  6. Phase to Elevation (PhaseToElevation, Radar > Interferometric > Products; help). It finds the unwrapped band by unit abs_phase (or a name starting with "Unw") and writes elevation in metres. Method defaults to DEM Seed: the unknown phase constant is fixed with low-slope points of a reference DEM (default Copernicus 30m Global DEM). Schwabisch needs no DEM; because unwrapped phase is only relative, expect a constant height offset and remove it with a point of known height. The product must still be in radar geometry and keep its latitude, longitude, incidence-angle and slant-range-time tie-point grids.
  7. Range-Doppler Terrain Correction (Terrain-Correction; help) of the elevation band, with Save DEM as band ticked to get the reference DEM on the same grid.

Check the result

  • Subtract the reference DEM (Band Maths). The difference should be noise around a constant, with no trend across the scene.
  • Jumps of exactly h2π along low-coherence lines are unwrapping errors.
  • Smooth blobs of tens of metres that do not follow the terrain are atmospheric delay. Compare with a second pair if you have one.
  • Layover and shadow areas carry no valid height; mask them with the Terrain Correction layover/shadow mask.

Common pitfalls

  • Removing the topographic phase before unwrapping. Nothing is left to convert to height.
  • Unwrapping with the DEFO cost mode, which does not model layover and steep slopes.
  • Terrain-correcting before Phase to Elevation. It refuses map-projected input.
  • Using a long temporal baseline over vegetation. Coherence is lost and the DEM is noise.
