Geocode-First InSAR with GSLC

GSLC Terrain Correction resamples a single-look complex image onto a map grid and keeps its phase. A stack of such geocoded SLCs (GSLCs) is interfered directly on the map grid, so the chain needs no Back-Geocoding, ESD, Deburst, Merge or final Terrain Correction. You get a geocoded interferogram and coherence, and after unwrapping, displacement. Input: Sentinel-1 IW/EW SLC (one sub-swath at a time) or stripmap SLC.

Before you start

  • Input: stripmap SLC (tested on Sentinel-1 SM and ENVISAT ASAR IMS) or Sentinel-1 IW/EW SLC after S-1 TOPS Split, still in burst form. Debursted TOPS products are refused; GRD products carry no phase.
  • One grid for all dates: every GSLC is snapped to a global standard grid with origin (0, 0); this is always on. Dates line up only if they use the same Grid Spacing setting, pixel spacing and map projection.
  • Keep the source SLCs: each GSLC records the path of its source SLC (gslc_source_slc_path). When Create Stack geocodes or re-geocodes a Secondary, it reloads the source SLCs to estimate the residual offset by cross-correlation. Do not move or delete them.
  • Orbits and DEM: as for the classical chain (precise orbits, Copernicus 30 m DEM by default).
  • Graphs: SNAP ships no ready-made GSLC graph; build one in the Graph Builder.

Steps

  1. Apply Orbit File (Apply-Orbit-File; help), on every date.
  2. S-1 TOPS Split (TOPSAR-Split; help), IW/EW only: the same sub-swath and the same ground bursts on every date. Optional: S-1 ETAD Correction on all dates or on none; for GSLC (IW) switch on both Resample image and Apply range-delay phase correction.
  3. Geocoded SLC Terrain Correction (GSLC-Terrain-Correction, Radar > Geometric > Terrain Correction; help), on the Reference date (and, if you like, on each Secondary). Parameters that matter:
    • Grid Spacing: NATIVE_ANISOTROPIC (default) keeps native sampling on both axes in rectangular cells. SQUARE_COARSEST gives square cells at the coarser axis and, for IW, discards about 4× of range detail. Use one setting for the whole stack.
    • Image Resampling Method: BISINC_5_POINT_INTERPOLATION (default).
    • Output phase-flattened complex data: off (default). A flattened pair is already a topography-removed interferogram (deformation, atmosphere, DEM and orbit residuals remain). Interferogram reads the gslc_output_flattened stamp and then does not subtract the flat-Earth phase again, but it refuses a stack that mixes flattened and natural-phase products, so use one setting for every date.
    • Restore TOPS azimuth carrier: off (default); Output separable phase terms: on (default). Keep both: Interferogram uses the phase-term bands to subtract the carrier difference exactly.
    • Apply Solid Earth Tide correction and Apply tropospheric correction: off by default. They change the flatteningPhase band (and the flattened output); the tide also shifts the sampling position by a sub-pixel amount. With the default (natural-phase) output, Interferogram does not read them and recomputes its reference phase without them, so they are not a tide or troposphere correction of the interferogram. In a fully flattened stack the modelled tide and dry delay are removed with the rest of the range model. Create Stack passes the Reference's DEM (including an external DEM file), tide and troposphere settings to the Secondaries it geocodes; an external DEM file must exist at the same path on this machine.
  4. Create Stack (CreateStack, Radar > Coregistration > Stack Tools; help). Make the Reference GSLC the reference product (by default the first in the list) and add the other dates either as raw SLCs (after steps 1 and 2) or as GSLCs. Auto-coregister GSLC slaves is on by default: raw SLCs are geocoded onto the Reference grid with the Reference's settings, the residual offset of each Secondary is measured against the Reference SLC (Back-Geocoding + ESD for TOPS, cross-correlation for stripmap), and the Secondary is geocoded again with it if it exceeds 0.05 pixel. A GSLC Secondary already on the Reference lattice, with the same flattening and carrier settings, is stacked as it is, without bias estimation; one that differs is re-geocoded like a raw SLC. Skip GSLC bias estimation (geometric only) is off by default; turn it on only for quick looks. Keep Resampling Type NONE (default).
  5. Interferogram Formation (Interferogram; help). The operator detects the geocoded stack and sets the read-only flag GSLC mode auto-detected. The flat-earth phase (and, if you tick Subtract topographic phase, off by default, the topographic phase) is removed on the map grid; on a flattened stack it is not subtracted again. Keep Subtract flat-earth phase ticked (default) on every GSLC stack, flattened ones included: the TOPS carrier difference and the burst seam steps are handled only when it (or Subtract topographic phase) is selected. Set Coherence Window (m). Subtract burst seam steps (GSLC) (off by default, TOPS only) removes residual phase steps at burst seams.
  6. Goldstein Phase Filtering, Snaphu Export / SNAPHU / Snaphu Import and Phase to Displacement, as in the Sentinel-1 DInSAR workflow (Goldstein, Snaphu Export, Phase to Displacement). Use FFT Block Extent (m) in Goldstein. The results are already on the map grid: no Terrain Correction.

For full IW coverage, run steps 2 to 6 per sub-swath.

Check the result

  • Create Stack log: for each Secondary that it geocodes it reports the estimated bias, for example "CreateStack: bias for slave ... Δrange=..., Δazimuth=...". A warning that bias estimation failed means the stack was built with geometric coregistration only. A GSLC Secondary already on the Reference lattice is logged as "stacking as-is" and gets no bias line.
  • Burst seams (TOPS): look for phase steps along the burst boundaries in the interferogram. If they are present, try Subtract burst seam steps (GSLC) and check that all dates had the same ETAD setting.
  • Coherence: compare with the classical chain only at the same window in metres. In IW radar geometry a 10 × 10 pixel window is about four times longer in azimuth than in ground range; on a map grid it is nearly square.
  • Noise everywhere: usually different grid settings or a missing source SLC. (A flattened/non-flattened mix is refused by Interferogram.)

Common pitfalls

  • Thermal Noise Removal before GSLC. It turns the SLC into intensity, and the phase is lost.
  • Feeding debursted IW products. GSLC needs the burst structure to deramp.
  • Different Grid Spacing settings across dates. The products then sit on different lattices.
  • Applying ETAD to some dates only. Interferogram stops on a GSLC stack that mixes corrected and uncorrected dates.
  • Running Range-Doppler Terrain Correction on GSLC results. They are already geocoded.
