RCM Thermal Noise Removal

RCM Thermal Noise Removal Operator

Removes (or re-introduces) the thermal noise of RADARSAT Constellation Mission (RCM) products, using the noise levels delivered with each product in metadata/calibration/noiseLevels_POL.xml. Each polarisation uses its own noise file; a polarisation without noise levels is reported as an error.

Noise model

  • The Beta Nought noise vectors are used as the reference, as specified by the RCM product schema. Sigma Nought and Gamma noise are derived from it using the incidence angle (σ0 = β0·sinθ, γ0 = β0·tanθ).
  • For ScanSAR GRD products the per-beam noise vectors are used, selected for each pixel through the product's GRD burst map, and multiplied by the per-beam azimuth noise level scaling, which describes how the noise varies along each burst (scalloping).
  • Values between LUT samples are linearly interpolated.

Input and output

  • Uncalibrated (DN, amplitude, intensity) input: the noise is converted to |DN|2 with the Beta Nought calibration gains (lutBeta_POL.xml) and the result is written as Intensity_POL. Calibrate afterwards with the Calibration operator.
  • Complex (SLC, GRC) input: the noise is removed from the detected power |i + jq|2, using the complex calibration convention |DN|2/A2; the output is an intensity band and the product sample type becomes DETECTED. ScanSAR SLC products are not supported.
  • Calibrated input (Beta0, Sigma0, Gamma0): the noise is subtracted in the same units and the band name is kept. A calibrated product whose bands are not named Sigma0, Gamma0 or Beta0 is refused, since its calibration type cannot be determined. Calibrated complex input is refused.
  • MLC products (C11, C12, C22 covariance bands) are not supported and are refused.
  • The operator must be applied to the delivered raster: multilooked, resampled or subsampled products are refused. Subsets without subsampling are supported.

The product annotation noiseSubtractionPerformed is checked and updated: noise cannot be removed twice, and can only be re-introduced into a product from which it was removed.

Parameters

  • Polarisations – Polarisations to process (default: all).
  • Remove Thermal Noise – Subtract the thermal noise.
  • Output Noise – Also output the noise in dB (NEP, NEBZ, NESZ or NEGZ band; NEP is in |DN|2). Its no-data value is NaN.
  • Re-Introduce Thermal Noise – Add back thermal noise that was previously removed.
  • Clip Negative Values – Replace negative values after noise subtraction by a small positive floor value. Disable it when the output will be multilooked, speckle filtered, composited or turned into a covariance matrix, since clipping before averaging biases the result upwards (see the Thermal Noise Removal help and ESA MPC-0392, section 6.2).
  • Clip Floor Value – The value given to clipped pixels (default 1.0E-5), in the units of the output. For uncalibrated (DN) input the output is |DN|2, so the floor is in DN2: the default 1.0E-5 becomes about 1.0E-5/A (around 1.0E-13 for typical RCM GRD gains) after calibration, i.e. effectively zero. For calibrated input the floor is in σ0, γ0 or β0 (linear). A floor of 0 follows ESA MPC-0392 Eq-2; when the input no-data value is also 0, the output no-data value is set to NaN so that clipped pixels are not taken for no-data (Calibration keeps the NaN no-data value).
