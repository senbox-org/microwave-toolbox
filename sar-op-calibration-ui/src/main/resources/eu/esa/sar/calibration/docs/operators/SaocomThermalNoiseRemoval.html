SAOCOM Thermal Noise Removal

SAOCOM Thermal Noise Removal Operator

Removes (or re-introduces) the thermal noise of SAOCOM-1A/1B products, using the noise vectors (NESZ, noise equivalent sigma zero) delivered with the product. Open it from Radar > Radiometric > SAOCOM Thermal Noise Removal, or use the GPT operator SAOCOM-Thermal-Noise-Removal. The operator refuses products of any other mission.

Note: on complex (SLC) products, i and q are scaled by the same factor, so the phase is kept and only the amplitude changes. The noise vector geometry is approximate (see Noise data below), so the corrected amplitudes are approximate too.

Noise data

  • The noise vectors are read from the noiseLut*.xml files in the product's Calibration folder. The SAOCOM reader stores them under Abstracted_Metadata > noise. The polarisation of each file is taken from its file name (HH, HV, VH or VV).
  • Each polarisation has one noise vector along range. It is stretched linearly over the image width (first value at the first column, last value at the last column), and the same value is used for every line. There is no azimuth variation.
  • If the product has no noise files, the operator writes a warning to the log and removes nothing.

Processing

The noise is handled in linear power. SAOCOM Level-1 images are delivered already calibrated in σ0 (CONAE product format, section 2.4.2.1), so the noise vector is subtracted from the pixel power without any further calibration factor:

  • Intensity bands (the Sigma0_POL bands of DI, GEC and GTC products as read by SNAP): the noise is subtracted and the band keeps its name and unit, so intensity bands are returned as intensity (power). Note that the CONAE format specification describes these images as amplitude values, while the SNAP reader labels them as intensity; check the units of your product before relying on the result.
  • Amplitude bands: the noise is subtracted from the power (amplitude2), then the square root is taken, so amplitude bands are returned as amplitude, with their name and unit kept. With Clip Negative Values the floor is applied to the power before the square root; without it, a negative power gives an amplitude of 0. Without noise data, amplitude bands are copied unchanged.
  • Complex (i/q) bands (SLC): the noise is subtracted from the power i2+q2, then i and q are both multiplied by √(new power / old power). The phase is kept. Without noise data, i and q are copied unchanged.
  • Pixels equal to the band's no-data value stay no-data.
  • Virtual bands are copied unchanged. Bands that are not real, imaginary, amplitude or intensity bands are not copied to the output.
  • After removal the attribute thermal_noise_removed in Abstracted_Metadata is set to true, and after re-introduction to false. It is written only when noise data was applied. The operator refuses to remove the noise from a product where it is already true, and to re-introduce it where it is not true.

Parameters

  • Polarisations – The polarisations to process. Only bands of the selected polarisations are processed and written to the output (empty = all). A selection that matches no band is an error.
  • Remove Thermal Noise – Subtract the thermal noise (default: on).
  • Re-Introduce Thermal Noise – Add the noise to the data instead (default: off). Turn Remove Thermal Noise off when using it; selecting both is an error.
  • Clip Negative Values – Replace values that become negative after noise subtraction by a small positive floor value of 1.0E-5 (linear power; amplitude bands then get the square root of this floor, and i/q pairs a magnitude of that size) (default: on). Disable it when the output will be multilooked, speckle filtered or otherwise averaged, since clipping before averaging biases the result upwards.

Prerequisites

  • A SAOCOM product opened with the SAOCOM reader, with noise files in its Calibration folder; a DI or SLC product
  • Run it on the full-width product, before range subsetting, multilooking or terrain correction: the noise vector is stretched over the image width
  • Thermal noise must not already be removed (unless re-introducing)
