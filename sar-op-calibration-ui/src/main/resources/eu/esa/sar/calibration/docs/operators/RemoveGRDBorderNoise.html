S-1 GRD Border Noise Removal

The Sentinel-1 (S-1) Instrument Processing Facility (IPF) is responsible for generating the complete family of Level-1 and Level-2 operation products. The processing of the RAW data into L1 products features number of processing steps leading to artefacts at the image borders.

These processing steps are mainly the azimuth and /range compression and the sampling start time changes handling that is necessary to compensate for the change of earth curvature. The latter is generating a number of leading and trailing "no-value" samples that depends on the data-take length that can be of several minutes. The former creates radiometric artefacts complicating the detection of the "no-value" samples.

These "no-value" pixels are not null but contain very low values, which complicates masking by thresholding.

Processor versions

From IPF 2.90 (March 2018) the processor sets the no-value pixels of IW and EW products to 0, so no masking is needed [1]; such products are passed through, with 0 flagged as no-data. This also applies to stripmap products; products from earlier IPF versions are processed.

Detection

The border is detected on the co-polarised band in strips at all four image edges (per line for the near and far range edges, per column for the first and last lines of a data take) and the same mask is applied to every band. Only the pixels between the image edge and the detected border are masked, so dark areas inside the image, such as calm water, are not masked. Very dark surfaces lying directly at an image edge can still be mistaken for border noise. When the input is a subset, only its edges that are also edges of the original image are searched.

  • ESA – the method of [1]: the annotated noise is subtracted and the border is the contiguous run of pixels from the edge whose denoised amplitude stays below the threshold. Requires the noise vectors of an IW or EW product from IPF 2.50 up to (not including) 2.90; it is refused for other IPF versions, for stripmap products, whose noise vectors do not describe the border, and for products without range noise vectors.
  • Bidirectional – after the bidirectional all-samples method of [2], with relative instead of absolute thresholds: a line has a border when its edge level is below 10% of the scene's median amplitude, and the border ends where the amplitude rises clearly above the edge level. It needs no annotation. When chosen explicitly it also runs on products from IPF 2.90 on, whether or not the option below is set.
  • Auto (default) – pass-through for products from IPF 2.90 on (Bidirectional when the option below is set); before that, ESA for IW/EW products from IPF 2.50 and Bidirectional for stripmap products and for products before IPF 2.50, whose noise vectors are not usable (the ESA method is refused for them). When an IW/EW product has no range noise vectors for the co-polarisation, Auto falls back to Bidirectional.

The detection works on the original Level-1 raster: multilooked or otherwise resampled input (whose pixel spacing differs from the annotated one) is refused. Products from IPF 2.90 on are passed through whatever their raster.

The border positions along each edge are then regularised: median filtered over 51 lines as in [2], set to their maximum within a moving window of 25 lines (so gradually widening borders are followed rather than flattened to their largest value) and widened by a 5-pixel buffer. This removes the residual noisy pixels and the isolated masked pixels reported for per-pixel thresholding [2, 3]. When the border is deeper than the searched margin, the whole margin is masked. The first and last lines of the image are only searched in the first and last slice of a data take (and in slice-assembled products). Lines that are border over the whole margin, at the start or end of a data take, are left to the first/last-line cut so they do not widen the near and far range cuts.

If Thermal Noise Removal has already been applied, the ESA method compares the amplitude itself with the threshold. The Bidirectional method then no longer masks a whole search margin that is dark throughout, because without the noise floor calm water cannot be told apart from a border deeper than the margin. Dark surfaces at an image edge are more easily mistaken for border noise after Thermal Noise Removal, so apply this operator first.

Parameters

  • Polarisations – Bands to output (the mask is always derived from HH or VV). Masked pixels are set to the band's no-data value; dB bands without a no-data value get NaN, since 0 dB is a valid value.
  • Border margin limit – Maximum border width searched at each edge (default 2000 pixels, at least 12).
  • Threshold – Denoised amplitude below which edge pixels are border noise (ESA method, default 0.5).
  • Border detection method – Auto, ESA or Bidirectional.
  • Also process products from IPF 2.90 and later – With Auto, run the Bidirectional detection on products from IPF 2.90 on as well. It has no effect on an explicit choice: Bidirectional always runs and ESA is refused from IPF 2.90 on.

Usage

Apply the operator to the uncalibrated product, before Thermal Noise Removal and Calibration: Apply-Orbit-File → Remove-GRD-Border-Noise → ThermalNoiseRemoval → Calibration. Applying it before subsetting is recommended.
