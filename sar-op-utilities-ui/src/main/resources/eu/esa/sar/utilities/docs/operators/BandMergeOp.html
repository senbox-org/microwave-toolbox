Band Merge

The Band Merge operator (BandMerge) puts the bands of several products that cover exactly the same pixel grid into one product. Use it to bring results of separate processing chains on the same scene back together, for example a terrain-corrected backscatter product and a product derived from it on the same grid.

Band Merge has no menu entry. Add it in the Graph Builder (operator group Raster) and connect two or more source products to it, or call it with GPT.

What it does

  • The first source product is the reference. The output takes its name, product type, size, metadata, tie-point grids and geocoding.
  • Every band of every source product is copied into the output, the reference's bands first. The pixel values are not resampled or changed.
  • When a band name already exists in the output, the copy gets the suffix _2, then _3, and so on.
  • The masks of every source are copied, and their band-grouping patterns are added to the output's.

The sourceBands parameter and the Source Bands list in the dialog have no effect: the operator always copies all bands. To keep only some bands, add a Band Select node before or after Band Merge.

Compatibility check

Every source product must match the reference, or the operator stops with "Product [...] is not compatible to reference product." A source matches when:

  • its width and height in pixels are the same as the reference's;
  • it has geocoding if and only if the reference has;
  • at the centres of the four corner pixels its latitude and longitude differ from the reference's by no more than geographicError degrees (default 1.0E-5, about 1 m).

Band Merge does not move pixels. Products on different grids must first be brought onto one grid, for example with Collocation or, for SAR images, coregistration.
