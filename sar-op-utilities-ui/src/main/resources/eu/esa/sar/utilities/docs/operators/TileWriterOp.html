Tile Writer

The Tile Writer operator (TileWriter) cuts a product into a regular grid of rectangular pieces and writes each piece to its own file. Every piece keeps all bands, tie-point grids and metadata of the source. Use it to split a large scene into parts that are easier to share or to process one at a time.

Tile Writer has no menu entry. Add it in the Graph Builder (operator group Tools) in place of a Write node, or call it with GPT. It writes its own files, so it needs no Write node after it.

How the grid is built

There are two ways to divide the image, set by Division By:

  • Tiles: you choose the Number of Tiles N. The grid has √N rows and √N columns, and each piece is (image width / √N) by (image height / √N) pixels. Choose a square number (4, 9, 16, 36, 64, 100 or 256). The list also offers 2, but with 2 the code builds a 1 × 1 grid while reserving two outputs, and the run fails.
  • Pixels: you choose the size of one piece, Pixel Size width and height (200 by 200 by default). The grid has (image width / piece width) columns and (image height / piece height) rows.

All divisions are whole-number divisions. When the image size is not an exact multiple of the piece size, the leftover pixels at the right and bottom edges are not written to any piece.

overlap (default 0) enlarges every piece by that many pixels on each side. At the left and top image edges the start is held at pixel 0 but the size is not reduced, so the extra pixels go to the far side. Pieces on the right and bottom edges are not clipped to the image. The dialog does not show overlap; set it in the graph XML or on the GPT command line.

Output files

The pieces are written in the folder of the target file, in the chosen format (BEAM-DIMAP by default). Each file is named after the target file with _1, _2, ... added before the extension. Numbering runs along the first row from left to right, then the next row. When the format is BEAM-DIMAP, each header is written again after the last tile, so it is complete.

The operator passes the source product through unchanged as its own target product. The pieces are only in the files it writes.

Dialog

  • Division By: Tiles or Pixels.
  • Number of Tiles: shown for Tiles.
  • Pixel Size: two fields, width and height in pixels, shown for Pixels.
  • Target Tile Products: the base name, the output format and the folder.
