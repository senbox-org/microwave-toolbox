Batch unwrapping of interferograms with SNAPHU

Batch SNAPHU Unwrapping

This tool is for the SNAP/PyRate integration but it is useful as a standalone tool as well.

Give it the multi-pair interferogram product that you exported with Snaphu Export (for example from Multi-Reference InSAR) and, as Snaphu Export folder, the sub-folder that Snaphu Export created inside its target folder (named after the product). That folder holds one <date>_<date>snaphu.conf file per pair; Snaphu Export writes these only for a stack with more than one Secondary. The tool runs SNAPHU for every configuration file and reads the results back.

Snaphu Install Location can be the snaphu executable itself or a folder.

  • An executable you select directly is used whatever its name (for example snaphu-2.0.6; on Windows it must be a .exe file). A file named snaphu that is not executable is made executable; any other file that is not executable is reported.
  • In a folder, the tool looks for an executable named exactly snaphu (snaphu.exe on Windows) in the folder or its subfolders, and uses it.
  • Otherwise the tool downloads the SNAPHU build for your system (Windows or Linux) over https into the folder, so the folder must be writable. On Linux the downloaded binary is made executable. The download is found and reused on later runs.
No build is downloaded for macOS: install SNAPHU yourself and set Snaphu Install Location to the snaphu executable or its folder, or the tool stops with an error saying so.

The target product keeps the geocoding, the metadata and every band of the input that is not a wrapped phase band, including the coh_* coherence bands. Each wrapped phase band is replaced by one UnwPhase_ifg_<tag> band per pair (the wrapped band name with the prefix Unw), with the unit abs_phase. The product can therefore go straight to SBAS Inversion or Empirical Tropospheric Correction; Snaphu Import is not needed. The unwrapped bands are read from the SNAPHU output files (UnwPhase_ifg_<tag>.snaphu.img) in the export sub-folder, which stay open until the product has been written, so do not move or delete that folder before then.

Logs for all SNAPHU runs are written out to the SNAPHU export directory, with the progress monitor printing out the current export step.

More information on phase unwrapping and how SNAPHU operates can be found in the corresponding SNAPHU export help pages.

Prerequisites

  • The multi-pair interferogram product (for example from Multi-Reference InSAR) with at least two bands of unit phase and at least one coherence band
  • Snaphu Export run on that product first
  • A writeable SNAPHU processing folder and install folder (on macOS, a SNAPHU you installed yourself)
