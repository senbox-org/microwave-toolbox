Snaphu Data Import

Importing results from SNAPHU processing

Important note

It is strongly advised before executing graph for exporting data for SNAPHU processing for user to get familiar with general principles of doing phase unwrapping.

SNAPHU Data Import Graph

The main purpose of SNAPHU data import function is two-fold:

  1. To import results of SNAPHU processing,
  2. To construct Interferometric product that will contain unwrapped phase band, and the metadata of the source interferometric product.

The import graph is visualized in the figure below.


The graph has two readers and one writer. 1-Read-Phase reads the wrapped interferogram product that you gave to Snaphu Export (with geocoding and InSAR metadata). 2-Read-Unwrapped-Phase reads the SNAPHU result: the ENVI header UnwPhase_ifg_<tag>.snaphu.hdr that Snaphu Export wrote into its sub-folder, or the saved product of Batch Snaphu Unwrap (not needed for SBAS Inversion, which reads the Batch Snaphu Unwrap product directly). The writer saves the result in BEAM-DIMAP.

Specifically the import graph performs the following:

1-Read-Phase:
Reads the wrapped interferogram product. It must be the first input: metadata, geocoding and (unless Do NOT save Wrapped interferogram is ticked) all of its bands, including the coh_* coherence bands, are taken from the first input that has geocoding. A Batch Snaphu Unwrap product is also geocoded, so with it the order decides; the wrong order fails with "requires an unwrapped phase product".
2-Read-Unwrapped-Phase:
Reads the unwrapped phase. Every band whose name contains "unw" or "band" gets the unit abs_phase. If the first input has exactly one Secondary, the band is renamed Unw_Phase_ifg_<ref-date>_<sec-date>; with more than one Secondary the names are kept (UnwPhase_ifg_<tag>).
3-SnaphuImport:
Arranges the metadata and merges the bands of the source product into a unwrapped phase product. In this step metadata and bands are arranged in a compatible form for further InSAR processing. Leave Do NOT save Wrapped interferogram unticked for SBAS Inversion: ticking it also drops the coherence bands.
4-Write:
Writes "unwrapped phase product" in the standard DIMAP format.

Prerequisites

  • Exactly two source products of equal width and height, in this order: the wrapped interferogram product you exported with Snaphu Export (with geocoding), then the SNAPHU result (UnwPhase_*.snaphu.hdr) or the saved Batch Snaphu Unwrap product (when you import a multi-pair stack one pair at a time, the first input is the previous Snaphu Import output)
  • The second product must contain a band whose name contains 'unw' or 'band'
