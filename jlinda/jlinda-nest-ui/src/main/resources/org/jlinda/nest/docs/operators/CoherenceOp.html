Coherence estimation (InSAR operator)

Coherence estimation

This operator estimates the interferometric coherence (0 = no correlation, 1 = full correlation) between the Reference and each Secondary of a coregistered stack, in a moving window. For complex (SLC) data, the operator first removes phase that would otherwise lower the estimate inside the window: the flat-earth phase, which it estimates itself from the orbits and product metadata (it does not need a polynomial from Interferogram Formation), and, by default, the topographic phase simulated from a DEM. It then applies a bias correction.

Note that this is a "general" coherence estimation operator and not exclusive only for InSAR applications. It can be utilized to estimate the coherence information from any stack of coregistered complex images. For detected (amplitude) stacks a coherence band is computed for each Secondary band against the Reference band of the same quantity; the flat-earth, topographic-phase and bias options then have no effect.

Why the values differ from the Interferogram Formation coherence: with default settings this operator removes the flat-earth and the topographic phase before estimating coherence, and then corrects the estimator bias. The coherence band written by Interferogram Formation removes only the flat-earth phase by default (topographic phase only if "Subtract topographic phase" is selected there), and it applies no bias correction. Both default to a 10-pixel range window. Here, Square Pixel is on by default, so the azimuth window is derived from the pixel spacings (about 10×3 for Sentinel-1 IW); if that derived azimuth window would be below 1, the range window is adjusted instead. In a graph (GPT), Interferogram Formation currently ignores Square Pixel and uses 10×10. Compare the two operators only with the same window sizes. For the same window, this operator gives lower values where coherence is low (bias correction) and higher values in steep terrain (topographic fringes removed).

In order to reduce the noise, as the post-processing step, you can perform multilooking (with Multilook Operator). In case of ESA's ERS and Envisat sensors, the factor 5:1 (azimuth:range) or similar ratio between the factors is chosen to obtain approximately square pixels (20x20 m^2 for factors 5 and 1). Of course the resolution decreases if multilooking is applied.

Operator parameters:

  • Coherence Range Window Size (cohWinRg): window size in range, in pixels; range 2–90, default 10.
  • Coherence Azimuth Window Size (cohWinAz): window size in azimuth, in pixels; range 2–90, default 10. With Square Pixel on, this value is not used (see below).
  • Square Pixel / Independent Window Sizes (squarePixel): default Square Pixel (on). The azimuth window size is computed from the range window size and the ground-range and azimuth pixel spacings, so that the window is about square on the ground. With Independent Window Sizes, both window sizes are used as entered.
  • Subtract flat-earth phase (subtractFlatEarthPhase): remove the flat-earth phase before estimating coherence. Default: on. Complex data only.
  • Degree of "Flat Earth" polynomial (srpPolynomialDegree): degree of the 2-D polynomial fitted to the flat-earth phase; values 1–8, default 5.
  • Number of "Flat Earth" estimation points (srpNumberPoints): number of points at which the flat-earth phase is computed for the polynomial fit; values 301, 401, ..., 1001, default 501.
  • Orbit interpolation degree (orbitDegree): degree of the orbit interpolation polynomial; values 1–5, default 3.
  • Subtract topographic phase (subtractTopographicPhase): simulate the topographic phase from a DEM and remove it before estimating coherence. Default: on. Complex data only.
  • Digital Elevation Model (demName): DEM used for the topographic phase; default Copernicus 30m Global DEM. Choose "External DEM" to use your own file.
  • External DEM (externalDEMFile): the external DEM file. No default.
  • DEM No Data Value (externalDEMNoDataValue): no-data value of the external DEM; default 0.
  • Apply Earth Gravitational Model (externalDEMApplyEGM): convert the external DEM heights from geoid to ellipsoid heights with the EGM; default on.
  • Tile Extension [%] (tileExtensionPercent): how much each tile is extended for the DEM simulation (an optimisation setting); default 100. The dialog offers 20, 40, 60, 80, 100, 150, 200.
  • Correct Coherence Bias (correctCoherenceBias): reduce the positive bias of the coherence estimate, which is largest for low coherence and small windows. The corrected value is γ − (1 − γ2) / (2N), where N is the number of pixels in the window, and it is not allowed to go below 0. Default: on. Complex data only.
  • Remove Local Phase Ramp (removeLocalPhaseRamp): in each window, estimate a linear phase ramp and remove it before estimating coherence. This reduces the loss of coherence caused by fringes that remain inside the window. Default: off.
  • Single Reference (singleMaster): default on. On: coherence between the stack Reference and each Secondary. Off: coherence between successive acquisitions (each acquisition paired with the next one, ordered by absolute orbit number).

Source bands:

  

Source Bands are set of, usually coregistered, bands of the complex product.
