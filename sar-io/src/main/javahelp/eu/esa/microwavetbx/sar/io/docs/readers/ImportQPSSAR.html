Import QPS-SAR

QPS-SAR is a constellation of small X-band SAR satellites operated by the Japanese company iQPS. SNAP reads QPS-SAR GeoTIFF products with the QPS-SAR reader, which uses GDAL.

Mission

  • Operator: iQPS Inc. (Institute for Q-shu Pioneers of Space), Japan.
  • Radar: X-band, 9.38 GHz, up to about 600 MHz bandwidth; HH or VV.
  • Orbit: inclined low Earth orbits; recent satellites fly at about 575–585 km.
  • Lifetime: first satellite (QPS-SAR-1) launched 11 December 2019; further satellites have been launched since, and the constellation is in operation.
  • Modes: Stripmap (about 1.8 m) and Spotlight (about 0.5 m).

Supported products

LevelProducts recognised by the reader
1.1SLC (complex), SLA (single-look amplitude), MLA (multi-look amplitude)
1.2Ground-range projected SLA and MLA
1.3Orthorectified SLA and MLA

Stripmap and Spotlight products are supported.

How to open

Select the product GeoTIFF (.tif). You can also select its .xml or .json metadata file; the reader then opens the GeoTIFF with the same name in the same folder. The file name must start with QPS-SAR, QPSSAR or QPS_SAR.

What you get

  • SLC: i_VV and q_VV bands and a virtual Intensity_VV band.
  • SLA and MLA: an Amplitude_VV band and a virtual Intensity_VV band.
  • The geocoding stored in the GeoTIFF.

The mission and acquisition parameters SNAP uses are listed in the Abstracted Metadata. For QPS-SAR it is only partly filled (see below).

Known limitations

  • Product type, level and mode are taken from the file name. A name without these keywords is treated as a detected Level 1.1 Stripmap product.
  • The polarisation is always set to VV and the radar frequency to 9.65 GHz; neither is read from the product. HH products are therefore labelled VV.
  • The XML file, if present, is only copied into the Original Product Metadata. Orbit state vectors, acquisition times and pixel spacing are not read, and the JSON file is not read at all.
  • SNAP has no QPS-SAR calibrator, so Calibration and Range-Doppler Terrain Correction cannot be used. Treat the data as uncalibrated images.

Recommended next step

For a quick look, use Multilook and Speckle Filter on SLA or MLA products. Level 1.3 products are already orthorectified.
