Import ALOS PALSAR

This page covers the first ALOS satellite (ALOS-1, "Daichi") and its PALSAR instrument. The reader is ALOS PALSAR CEOS under File > Import > SAR Sensors. ALOS-2 has its own page, Import ALOS-2, and so does ALOS-4, Import ALOS-4.

Mission

  • Operator: JAXA (Japan Aerospace Exploration Agency).
  • Instrument: PALSAR, L-band SAR at 1270 MHz (wavelength about 23.6 cm).
  • Orbit: sun-synchronous, about 692 km altitude, 46-day repeat cycle.
  • Lifetime: launched 24 January 2006. Operations ended in April 2011; JAXA retired the satellite on 12 May 2011.

Supported products

LevelsL1.1 (single-look complex, slant range); L1.5 (detected, ground range)
ModesFine Beam Single, Fine Beam Dual, Polarimetric, ScanSAR
PolarisationsFine Beam Single and ScanSAR: HH or VV; Fine Beam Dual: HH+HV or VV+VH; Polarimetric: HH+HV+VH+VV

The reader also opens ALOS PALSAR products processed by ESA's ALOS processor.

How to open

Select the volume file VOL-ALPSR.... The leader, image (IMG-) and trailer files must be in the same folder. You can also select a ZIP archive whose name starts with ALPSR, ALOS (not ALOS2) or AL1.

What you get

  • L1.1: complex bands i_HH and q_HH (units real and imaginary) per polarisation, plus a virtual Intensity_HH band.
  • L1.5: detected Amplitude_HH per polarisation, plus a virtual Intensity_HH band.
  • Tie-point grids (latitude, longitude, slant range time, incidence angle) and orbit state vectors from the leader file.
  • Mission and acquisition parameters are in the Abstracted Metadata.

Known limitations

  • JAXA Level 1.1 SLCs are focused in a squinted (non-zero-Doppler) geometry. Apply ALOS Deskewing before coregistration or terrain correction.
  • Level 1.0 (raw signal) products are not focused by SNAP.
  • Apply Orbit File has no ALOS orbit type; SNAP uses the orbit in the leader file.

Recommended next step

  • Detected products: Radiometric Calibration → Speckle Filter → Range Doppler Terrain Correction.
  • JAXA SLCs: ALOS Deskewing → Create Stack → Interferogram; quad-pol SLCs: Polarimetric Matrices.

Product format specification

JAXA's PALSAR Level 1.0 and Level 1.1/1.5 product format descriptions: https://www.eorc.jaxa.jp/ALOS/en/doc/format.htm. Mission overview: https://www.eoportal.org/satellite-missions/alos.
