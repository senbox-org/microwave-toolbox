Import Gamma

The Gamma reader (File > Import > SAR Formats > Gamma) opens raster files written by the GAMMA SAR and interferometry software, as used in StaMPS processing chains. Each raster is a plain binary file described by a text parameter file.

Format

  • A parameter file with the extension .par (or .diff_par) holds the image size, data type, byte order, timing, radar frequency, PRF, looks and pixel spacing.
  • The data file has the same name without the .par extension, for example 20200101.rslc for 20200101.rslc.par.
  • No mission is implied: the sensor name is copied from the parameter file.

Supported data

  • Complex: files whose name before .par ends in slc (this includes coregistered .rslc) or diff. Data types SCOMPLEX (16-bit integer pairs) and FCOMPLEX (32-bit float pairs).
  • Real-valued: any other file, read as 32-bit float.

How to open

Select the parameter file, for example 20200101.rslc.par. The data file must be in the same folder. Every file in that folder whose name starts with the parameter file's base name is loaded as a band.

What you get

  • Complex files: bands i_<data file name> and q_<data file name> (units real and imaginary), plus virtual intensity and phase bands.
  • Real-valued files: one band named after the data file, without a unit.
  • Product type SLC for complex data, otherwise the data type from the header. Coregistered .rslc files are flagged as a coregistered stack.
  • Timing, radar frequency, PRF, looks and pixel spacing are copied into the Abstracted Metadata.

Known limitations

  • The reader was written for the GAMMA products used in StaMPS processing; other GAMMA outputs may not open correctly.
  • No geocoding and no orbit state vectors are created. Operators that need them, such as terrain correction, coregistration and interferogram formation, cannot be run on the imported product.

Recommended next step

Inspect the bands in the viewer or derive values with Band Maths. To prepare SNAP interferograms for StaMPS, use StaMPS Export; to write a SNAP product in GAMMA format, use File > Export > SAR Formats > Gamma.

Product format specification

The format is defined in the documentation of the GAMMA software (GAMMA Remote Sensing AG); no public specification is linked here.
