Import RAT

The RAT reader opens raster files in the RAT format as used by DLR's TAXI processing software. It is a file format, not a mission.

Format

A RAT product is a binary image file (.rat) with an ENVI-style text header next to it (.rat.hdr).

Supported data

  • Complex data (ENVI complex float32 or float64), stored pixel-interleaved (I, Q per pixel).
  • Any other ENVI data type, read like an ENVI file.

How to open

Use File > Import > SAR Formats > RAT or File > Open Product and select the header file, <name>.rat.hdr. The image data must be in <name>.rat in the same folder.

What you get

  • Complex data: bands i_band and q_band (real and imaginary parts) and a virtual Intensity_band.
  • Other data types: the bands as described in the header.
  • Geocoding from the header's map info, if present. The header's description and fields are kept in the metadata.

Known limitations

No SAR metadata is read: the product has no orbit, timing or radar parameters in its Abstracted Metadata. Operators that need them, such as Calibration or Range-Doppler Terrain Correction, cannot be used.

Recommended next step

Display the bands, or derive values with Band Maths.

Product format specification

The header follows the ENVI header format; see the SNAP ENVI reader page.
