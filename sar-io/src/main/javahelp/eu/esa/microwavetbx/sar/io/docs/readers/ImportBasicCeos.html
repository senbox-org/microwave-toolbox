Import Basic CEOS

The Basic CEOS reader is a generic fallback for SAR products in CEOS format that no mission reader recognises. Use a mission reader whenever one exists: it reads the mission-specific records and sets the metadata that calibration and other operators need.

Format

A CEOS SAR product is a set of binary files: a volume directory file, a leader file with the scene, processing and orbit records, one image file per channel or polarisation, and optionally a trailer file. Each agency defines its own variant of the records.

Supported data

FileName starts with
Volume directoryVDF or VOL (or ends with .VDF / .VOL)
LeaderLEA or SARL
ImageDAT, IM or SARD
Trailer (optional)TR or SART

The mission readers (for example ERS, JERS-1, ALOS PALSAR, ALOS-2, ALOS-4, RADARSAT-1 and StriX) claim their products first; Basic CEOS only reports itself as "suitable", so it is chosen when no mission reader accepts the volume file.

How to open

Use File > Open Product and select the volume directory file. The leader, image and trailer files must be in the same folder. There is no entry under File > Import.

What you get

  • Complex products (product type containing SLC, COMPLEX, SLANT or 1.1): bands i and q (units real and imaginary) and a virtual Intensity band.
  • Detected products: an Amplitude band and a virtual Intensity band.
  • With several image files, the band names get a suffix _1, _2, …
  • Tie-point grids (slant range time, incidence angle, latitude, longitude) and the orbit state vectors from the leader file. The values read are in the Abstracted Metadata.

Known limitations

  • The reader records the mission as RS1 (RADARSAT-1) whatever the satellite, so mission-specific operators such as Calibration do not handle the product correctly.
  • All image files must have the same size.
  • Records that differ from the RADARSAT-1 layout can give wrong or missing metadata. Check the Abstracted Metadata before processing.

Recommended next step

  • Detected products: Multilook → Speckle Filter → Range Doppler Terrain Correction, which uses the orbit from the leader file.
  • If your mission has its own reader (see Supported Missions), open the product with that reader instead.

Product format specification

There is no single CEOS SAR specification; each agency publishes the format description of its products. See the mission pages, for example JAXA's ALOS-2 format documents: https://www.eorc.jaxa.jp/ALOS-2/en/doc/format.htm.
