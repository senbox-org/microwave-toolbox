Import SAOCOM

SAOCOM is Argentina's L-band SAR mission. Its two satellites fly together with Italy's COSMO-SkyMed in the SIASGE system. SNAP reads SAOCOM Level-1 products with the SAOCOM reader.

Mission

  • Operator: CONAE, the Argentine space agency.
  • Radar: L-band, 1.275 GHz (wavelength about 23.5 cm).
  • Orbit: sun-synchronous at about 620 km; 16-day repeat per satellite, 8 days for the pair.
  • Satellites: SAOCOM-1A launched 7 October 2018, SAOCOM-1B launched 30 August 2020.
  • Modes: Stripmap, TOPSAR Narrow and TOPSAR Wide.
  • Polarisation: single (HH or VV), dual (HH+HV or VV+VH) or quad.

How to open

A SAOCOM delivery is an .xemt metadata file plus the product data, either unpacked in a folder or as a .zip with the same name. Select the .xemt file (names start with S1A or S1B), or the folder that contains it. Keep the .zip next to the .xemt; the reader opens it directly.

What you get

  • SLC: i_ and q_ bands per polarisation and virtual Intensity_ bands. TOPSAR products get one set per sub-swath, for example i_S1_HH, i_S2_HH.
  • DI, GEC, GTC: Sigma0_ bands per polarisation. They are already calibrated to σ° (linear intensity).
  • Incidence-angle and slant-range-time tie-point grids; GEC and GTC take the map geocoding of the GeoTIFF.

The mission and acquisition parameters SNAP uses are listed in the Abstracted Metadata.

Known limitations

  • Only SLC products need Calibration; detected products are already σ°.
  • Apply Orbit File has no SAOCOM orbit source; the reader uses the orbit in the annotation.

Recommended next step

For SLC: Calibration, then Multilook or an InSAR or polarimetric chain. For DI: Speckle Filter and Range-Doppler Terrain Correction.
