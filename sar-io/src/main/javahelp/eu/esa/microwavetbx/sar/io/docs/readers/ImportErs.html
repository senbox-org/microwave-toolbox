Import ERS-1/2 SAR

This page covers SAR image products from ERS-1 and ERS-2 in both formats SNAP can read: Envisat format (opened by SNAP's ENVISAT reader, as for ASAR) and CEOS format (reader ERS CEOS, menu File > Import > SAR Sensors > ERS 1/2 CEOS).

Mission

  • Operator: European Space Agency (ESA).
  • Instrument: AMI SAR, C-band at 5.3 GHz (wavelength about 5.66 cm), VV polarisation, about 100 km swath and about 30 m resolution.
  • Orbit: sun-synchronous, 782–785 km altitude; 35-day repeat cycle for most of the mission (ERS-1 also flew 3-day phases).
  • ERS-1: launched 17 July 1991, ended 10 March 2000.
  • ERS-2: launched 21 April 1995, taken out of service 5 September 2011. During the tandem mission (1995–1996) ERS-2 followed ERS-1 one day later in the same orbit.

ESA currently distributes ERS SAR products in Envisat format. CEOS products come from older processing chains (PGS or VMP processors).

How to open

  • Envisat format: select the file ending in .E1 (ERS-1) or .E2 (ERS-2). A .zip or .gz containing it can be selected directly.
  • CEOS format: select the volume file whose name starts with VDF. The leader (LEA), image (DAT) and trailer files must be in the same folder. You can also select a ZIP archive whose name starts with ER01, ER02, E1_, E2_ or SAR_.

What you get

  • SLC: complex bands i and q (units real and imaginary) plus a virtual Intensity.
  • Detected products: Amplitude plus a virtual Intensity.
  • In CEOS products with several image files the bands get a numeric suffix (Amplitude_1, ...).
  • Tie-point grids (latitude, longitude, slant range time, incidence angle) and orbit state vectors. The mission is recorded as ERS1 or ERS2 in the Abstracted Metadata.

Known limitations

  • Only Envisat-format and CEOS-format products are readable. SNAP has no reader for ERS SAR products repackaged in other formats, such as SAFE.
  • After the ERS-2 tape recorders failed in 2003, data were only acquired within view of a ground station (mostly Europe and Canada), so global coverage ends there.

Recommended next step

  • Apply Orbit File (DELFT or PRARE precise orbits) → Radiometric Calibration → Range Doppler Terrain Correction.
  • SLC for interferometry: Apply Orbit File → Create Stack → Interferogram. See InSAR concepts.
