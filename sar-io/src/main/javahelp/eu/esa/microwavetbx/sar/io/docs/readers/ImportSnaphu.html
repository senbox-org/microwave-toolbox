Import SNAPHU Result

SNAPHU is an external program for two-dimensional phase unwrapping, based on the algorithm of C. W. Chen and H. A. Zebker. The SNAPHU reader opens the unwrapped phase that SNAPHU writes after Snaphu Export, so that Snaphu Import can bring it back into SNAP.

Format

Snaphu Export writes a folder with the wrapped phase and coherence as raw binary files with ENVI-style headers (.snaphu.hdr and .snaphu.img), the configuration file snaphu.conf, and, in advance, the header of the result: UnwPhase_ifg_<tag>.snaphu.hdr. Running SNAPHU with snaphu.conf writes the unwrapped phase as 32-bit floating-point data to UnwPhase_ifg_<tag>.snaphu.img in the same folder.

Supported data

  • Real-valued rasters described by a *.snaphu.hdr header (the unwrapped phase).
  • Complex rasters (ENVI data types 6 and 9, pixel-interleaved real and imaginary parts).

How to open

Select the header UnwPhase_ifg_<tag>.snaphu.hdr in the Snaphu Export folder. The data file must be in the same folder and have the same name up to the first dot. Usually you do not open it on its own: the second reader of the Snaphu Import graph opens it for you. There is no entry under File > Import; use File > Open Product.

What you get

  • Real data: one band per entry in the header's band names, for the SNAPHU result one band UnwPhase_ifg_<tag> holding the unwrapped phase in radians.
  • Complex data: bands i_band and q_band (units real and imaginary) and a virtual Intensity_band.
  • No SAR metadata and no geocoding: the header written by Snaphu Export has no map information.

Known limitations

  • The band has no phase unit and the product has no SAR metadata, so InSAR operators cannot use it directly. Snaphu Import sets the unit to absolute phase and copies the metadata and geocoding of the wrapped interferogram.
  • The reader works on the header file only; it does not open the snaphu.conf or log files.

Recommended next step

  • Snaphu Import with the wrapped interferogram as first input, then Phase to Displacement or Phase to Elevation.
