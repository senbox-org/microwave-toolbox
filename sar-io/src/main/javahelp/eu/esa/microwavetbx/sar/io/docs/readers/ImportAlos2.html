Import ALOS-2 PALSAR-2

SNAP has two ALOS-2 readers: ALOS-2 CEOS for products in CEOS format and ALOS-2 GeoTIFF for detected products in GeoTIFF format. Both are under File > Import > SAR Sensors. ALOS (PALSAR) products have their own page, Import ALOS PALSAR; ALOS-4 has its own readers, see Import ALOS-4.

Mission

  • Operator: JAXA (Japan Aerospace Exploration Agency).
  • Instrument: PALSAR-2, L-band SAR. Centre frequency 1236.5, 1257.5 or 1278.5 MHz (wavelength about 24 cm).
  • Orbit: sun-synchronous, 628 km altitude, 14-day repeat cycle.
  • Launch: 24 May 2014. The satellite is in extended operations.

How to open

  • CEOS: select the volume file VOL-ALOS2.... The leader (LED-), image (IMG-) and trailer (TRL-) files must be in the same folder. You can also select a ZIP archive that contains the volume file.
  • GeoTIFF: select one of the image files IMG-HH-ALOS2...tif (or -HV-, -VV-, -VH-). The file summary.txt must be in the same folder. All polarisation files in the folder are loaded into one product.

What you get

  • L1.1 (CEOS): complex bands i_HH and q_HH (units real and imaginary) per polarisation, plus a virtual Intensity_HH band.
  • L1.5 (CEOS) and GeoTIFF: detected Amplitude_HH per polarisation, plus a virtual Intensity_HH band.
  • CEOS products carry tie-point grids (latitude, longitude, slant range time, incidence angle) and orbit state vectors from the leader file. GeoTIFF products take their map geocoding from the GeoTIFF.
  • Mission and acquisition parameters are in the Abstracted Metadata.

Known limitations

  • The GeoTIFF reader treats every image as detected amplitude and fills only basic metadata: no orbit state vectors and no calibration constant. For radiometric calibration, InSAR or polarimetry, order the products in CEOS format.
  • ALOS-2 products are in zero-Doppler geometry. The ALOS Deskewing operator is for ALOS (PALSAR) only and is not needed.
  • Apply Orbit File has no ALOS-2 orbit type; SNAP uses the orbit in the leader file.

Recommended next step

  • Detected products: Radiometric Calibration → Speckle Filter → Range Doppler Terrain Correction.
  • L1.1 SLC for interferometry: Create Stack or DEM Assisted Coregistration → Interferogram. See InSAR concepts.
  • Quad-pol L1.1: Polarimetric Matrices.
