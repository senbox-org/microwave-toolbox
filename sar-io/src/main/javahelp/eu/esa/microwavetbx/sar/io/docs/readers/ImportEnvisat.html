Import ENVISAT ASAR

ASAR products in Envisat format are opened by SNAP's ENVISAT reader, which is part of the SNAP core. The same reader opens ERS SAR products in Envisat format (see Import ERS-1/2 SAR) and the Envisat optical instruments, which are not covered here.

Mission

  • Operator: European Space Agency (ESA).
  • Instrument: ASAR (Advanced SAR), C-band at 5.331 GHz (wavelength about 5.6 cm).
  • Orbit: sun-synchronous, about 800 km altitude, 35-day repeat cycle. From October 2010 the orbit was lowered to about 783 km with a 30-day repeat cycle.
  • Lifetime: launched 1 March 2002; contact was lost on 8 April 2012, which ended the mission.

Browse products (ASA_*_BP) and the external calibration file (ASA_XCA_AX) can also be opened.

How to open

Select the product file ending in .N1. A .zip or .gz file that contains it can be selected directly.

What you get

  • SLC: i_1 and q_1 (units real and imaginary) plus a virtual Intensity_1. AP SLCs add i_2/q_2 for the second polarisation; WS SLCs have one pair per sub-swath (i_1 to q_5).
  • Detected products: Amplitude plus a virtual Intensity; AP products have Amplitude_1 and Amplitude_2. The polarisation of each dataset is given by mds1_tx_rx_polar and mds2_tx_rx_polar in the Abstracted Metadata.
  • Tie-point grids latitude, longitude, slant_range_time and incident_angle from the geolocation grid, and orbit state vectors.
  • Mission and acquisition parameters are in the Abstracted Metadata.

Known limitations

  • Only Envisat-format products are readable. SNAP has no reader for ASAR products repackaged in other formats, such as SAFE.
  • Wave Mode products open, but the SAR processing operators are meant for image products.

Recommended next step

  • Apply Orbit File (DORIS precise or DELFT orbits) → Radiometric Calibration → Range Doppler Terrain Correction.
  • SLC for interferometry: Apply Orbit File → Create Stack → Interferogram.
