Import PolSARPro

PolSARPro is ESA's open-source polarimetric SAR toolbox. The PolSARPro reader opens a PolSARPro output folder as one SNAP product.

Format

PolSARPro stores polarimetric matrices such as T3 or C3 as one binary file per matrix element (.bin) with an ENVI header (.bin.hdr), plus a config.txt file in the folder.

Supported data

PolSARPro output folders, for example T3 or C3 folders, and folders that SNAP wrote when it exported a product in PolSARPro format.

How to open

Select the folder's config.txt file or one of its *.bin.hdr header files. The folder must contain both config.txt and at least one *.bin.hdr file. The reader then loads every band in the folder that has a header and a data file.

What you get

  • One band per .bin file, named from its ENVI header (normally the matrix element, for example T11, T12_real, T12_imag).
  • Complex ENVI data are split into i_ and q_ bands with a virtual intensity band.
  • The product is marked as polarimetric data in its Abstracted Metadata.
  • Geocoding from the ENVI map info, if the header has one.

Restoring the SAR metadata

PolSARPro output carries no SAR metadata. The reader loads it from an XML file if one is present: first a file with the same name as the selected file and the extension .xml, otherwise a metadata.xml file in the same folder. SNAP writes such files when it exports a product in PolSARPro format.

You can also copy the metadata from the original product:

  1. Open the original product and the PolSARPro product. Both must have the same raster size.
  2. Select the PolSARPro product and choose Tools > Metadata > Replace Metadata.
  3. In the dialog, select the original product as the metadata source.

In a graph, use the ReplaceMetadata operator. Connect the product that receives the metadata first and the original product second. The resulting Abstracted Metadata allows operators such as terrain correction to run.

Known limitations

  • Without the metadata step, operators that need orbit or timing information cannot be used.
  • Only one product per folder: the reader always loads the whole folder.

Product format specification

PolSARPro and its documentation are distributed through ESA's STEP platform: https://step.esa.int/main/toolboxes/polsarpro-v6-0-biomass-edition-toolbox/. The headers follow the ENVI header format; see the SNAP ENVI reader page.
