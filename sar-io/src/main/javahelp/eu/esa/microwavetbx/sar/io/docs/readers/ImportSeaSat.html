Import Seasat

Seasat was NASA's 1978 ocean-observation satellite, with an L-band SAR on board. SNAP reads the Seasat products distributed by the Alaska Satellite Facility (ASF) with the SeaSat reader.

Mission

  • Operator: NASA/JPL.
  • Radar: L-band, 1.275 GHz (wavelength about 23.5 cm), HH polarisation.
  • Orbit: about 800 km altitude.
  • Lifetime: launched 26 June 1978 (27 June UTC); an electrical short circuit ended the mission in October 1978, after 105 days in orbit.
  • Imaging: stripmap, about 25 m resolution, 100 km swath.

Supported products

Detected ground-range products (for example SS_00263_STD_F0886): GeoTIFF image with an XML metadata file. HH only.

How to open

Select the product XML file SS_*.xml (not the .iso.xml file) in the unpacked folder, or the zipped product SS_*.zip.

What you get

  • An Amplitude_HH band and a virtual Intensity_HH band.
  • Geocoding from the GeoTIFF, plus tie-point grids.

The mission and acquisition parameters SNAP uses are listed in the Abstracted Metadata.

Known limitations

  • SNAP has no Seasat calibrator, so Calibration does not accept these products.
  • Apply Orbit File has no Seasat orbit source.

Recommended next step

Speckle Filter, then Range-Doppler Terrain Correction or Ellipsoid Correction.
