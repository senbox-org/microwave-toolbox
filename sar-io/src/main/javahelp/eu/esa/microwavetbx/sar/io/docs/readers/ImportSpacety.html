Import Spacety

Spacety is a Chinese company that operates small C-band SAR satellites, starting with HiSea-1 and Chaohu-1. Its products use a SAFE-like layout with a manifest.safe file. SNAP reads them with the Spacety reader.

Mission

  • Operator: Spacety (China).
  • Radar: C-band, 5.4 GHz (wavelength about 5.6 cm). HiSea-1 images in VV.
  • Satellites: HiSea-1 launched 22 December 2020; Chaohu-1 launched 27 February 2022.
  • Modes (HiSea-1): Spotlight (about 1 m, 5 km swath), Stripmap (about 3 m, 20 km), Scan (about 10 m, 50 km) and Wide Scan (about 20 m, 100 km).

Supported products

  • SLC (Single Look Complex, slant range) in Stripmap, Spotlight and ScanSAR modes.
  • Detected products.

How to open

Select the manifest.safe file inside the product folder (the folder name starts with BC or BX, for example BC1_SM_SLC_1SSV_...), the folder itself, or the zipped product with the same name.

What you get

  • SLC: i_ and q_ bands per polarisation (for example i_VV) and virtual Intensity_ bands. ScanSAR products get one set per sub-swath, with the sub-swath name added to the band name.
  • Detected products: Amplitude_ bands and virtual Intensity_ bands.
  • Tie-point grids for latitude, longitude, incidence angle, elevation angle and slant-range time.
  • The calibration look-up tables of the product, used by Calibration.

The mission and acquisition parameters SNAP uses are listed in the Abstracted Metadata.

Known limitations

  • Orbit state vectors come from the product annotation. Apply Orbit File has no Spacety orbit source.

Recommended next step

Calibration, then Multilook and Speckle Filter, and Range-Doppler Terrain Correction.
