Import ICEYE

The ICEYE reader (File > Import > SAR Sensors > ICEYE) opens ICEYE products delivered in the legacy HDF5 format. ICEYE products in Cloud-Optimized GeoTIFF (COG) format, including ICEYE Open Data, are opened by a separate reader: see Import ICEYE COG.

Mission

  • Operator: ICEYE (Finland), a commercial constellation of X-band SAR microsatellites.
  • Instrument: X-band SAR near 9.65 GHz (wavelength about 3.1 cm), VV polarisation.
  • Orbit: mostly sun-synchronous low Earth orbits, roughly 500–610 km altitude, plus some mid-inclination orbits.
  • Launch: the first satellite, ICEYE-X1, was launched on 12 January 2018. Many more have been launched since.

Imaging modes: Spot, Strip and Scan (and their variants). Polarisation: VV.

How to open

Select the HDF5 file ICEYE_....h5. You can also select the XML file ICEYE_....xml when an .h5 file with the same name lies beside it; the reader then opens the .h5.

What you get

  • SLC: complex bands i_VV and q_VV (units real and imaginary) plus a virtual Intensity_VV.
  • Detected HDF5: an Amplitude band plus a virtual Intensity.
  • Tie-point grids for incidence angle and slant range time, geocoding and orbit state vectors.
  • Acquisition parameters are in the Abstracted Metadata.

Known limitations

  • This reader opens HDF5 files only. ICEYE GeoTIFF and COG files go to the ICEYE COG reader.
  • Apply Orbit File has no ICEYE orbit type; SNAP uses the orbit in the product.

Recommended next step

  • Radiometric Calibration → Multilook (SLC) → Speckle Filter → Range Doppler Terrain Correction.
  • SLC stacks for interferometry or change detection: Create Stack.
