Import Sentinel-1

Sentinel-1 is the C-band SAR mission of the EU Copernicus programme, operated by ESA. SNAP reads Sentinel-1 SAFE products with the SENTINEL-1 reader, and GRD products in Cloud-Optimised GeoTIFF packaging with the SENTINEL-1 COG reader.

Mission

  • Radar: C-band, 5.405 GHz (wavelength about 5.55 cm).
  • Orbit: sun-synchronous at 693 km; 12-day repeat per satellite, 6 days with two satellites.
  • Modes: Stripmap (SM), Interferometric Wide swath (IW, 250 km, three TOPS sub-swaths), Extra Wide swath (EW, five sub-swaths) and Wave (WV).
  • Polarisation: SM, IW and EW single (HH or VV) or dual (HH+HV or VV+VH); WV single only.

How to open

Select the manifest.safe file inside the .SAFE folder, the .SAFE folder itself, or the downloaded .zip (name starting with S1). SNAP picks the right reader: GRD products whose measurement files end in cog.tiff go to the COG reader. The Copernicus Data Space Ecosystem distributes GRD as COG packaging, where only the measurement GeoTIFFs differ from the classic SAFE.

What you get

  • IW and EW SLC: one i_/q_ band pair per sub-swath and polarisation, for example i_IW1_VV and q_IW1_VV, plus a virtual Intensity_IW1_VV. Each sub-swath still contains its separate bursts; see TOPS.
  • SM SLC: i_VV, q_VV, Intensity_VV. WV SLC: one set per vignette, for example i_WV1_IMG001_VV.
  • GRD: Amplitude_VV, Amplitude_VH (16-bit) with virtual Intensity_ bands.
  • Tie-point grids: latitude, longitude, incident_angle, elevation_angle, slant_range_time (prefixed with the sub-swath for IW/EW SLC, for example IW1_latitude).
  • Calibration and noise look-up tables, read from the annotation, for Calibration and Thermal Noise Removal.
  • OCN: the geophysical variables (owi, osw, rvl groups) as bands.

The mission and acquisition parameters SNAP uses are listed in the Abstracted Metadata.

ETAD products

Sentinel-1 ETAD (Extended Timing Annotation Dataset) products, with _ETA_ in the name, are not read by these readers. They open with the separate SENTINEL-1 ETAD reader (select the ETAD manifest.safe or .zip); see Import Sentinel-1 ETAD. Use them with S-1 ETAD Correction and ETAD Deburst; background in Orbits and ETAD.

Known limitations

  • Level-0 products open for inspection of their metadata only; SNAP does not focus raw data.
  • Bursts are not merged on reading. Run TOPSAR-Deburst before operators that need a continuous image.

Recommended next step

  • GRD: Apply Orbit File → Remove GRD Border Noise → Thermal Noise Removal → Calibration → Speckle Filter → Range-Doppler Terrain Correction.
  • IW SLC for InSAR: TOPSAR-Split → Apply Orbit File → Back-Geocoding → Interferogram Formation → TOPSAR-Deburst.
