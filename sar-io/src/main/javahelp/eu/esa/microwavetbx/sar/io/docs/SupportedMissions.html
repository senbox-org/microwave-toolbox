Supported Missions and Readers

This page lists the product readers of the Microwave Toolbox for SAR missions, SAR file formats and the CIMR radiometer, with the files each one opens and a link to its help page. Most readers are under File > Import > SAR Sensors or SAR Formats. File > Open Product picks the reader automatically, except for Generic Binary and Complex Generic Binary, which need their import dialog.

Readers

The reader column gives the format name used in File > Open Product, in graphs (Read operator, formatName) and in gpt. "(folder or file name)" means that the reader recognises the product by its file names rather than by an extension.
