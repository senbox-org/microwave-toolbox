Import StriX

StriX is the X-band small-SAR constellation of the Japanese company Synspective. SNAP has two readers: StriX for SLC products in CEOS format and StriX GRD for GRD products in XML + GeoTIFF format.

Mission

  • Operator: Synspective Inc. (Japan).
  • Radar: X-band, about 9.65 GHz (wavelength about 3.1 cm), VV.
  • Lifetime: first satellite (StriX-α) launched 15 December 2020; more satellites have been launched since, and the constellation is in operation.
  • Orbit: sun-synchronous orbits at about 570–580 km, and inclined orbits (35°) for later satellites.
  • Modes: Stripmap (about 3 m, 10–30 km swath) and Sliding Spotlight (below 1 m, about 10 km swath).

How to open

  • SLC: select the volume file (VOL-STRIX...), the product folder, or a .zip that contains the volume file.
  • GRD: select the metadata file PAR-*.xml; the matching .tif must be in the same folder. A .zip whose name starts with PAR- also works.

What you get

  • SLC: i_VV and q_VV bands and a virtual Intensity_VV band; tie-point grids for latitude, longitude, incidence angle and slant-range time.
  • GRD: an Amplitude_VV band and a virtual Intensity_VV band, with the geocoding of the GeoTIFF and, when the metadata gives near and far incidence angles, an incidence-angle tie-point grid.

The mission and acquisition parameters SNAP uses are listed in the Abstracted Metadata.

Known limitations

  • GRD metadata contains no orbit state vectors, so operators that need the orbit, such as Range-Doppler Terrain Correction, cannot be used on GRD products.
  • Apply Orbit File has no StriX orbit source.

Recommended next step

Calibration (StriX is supported), then Multilook and Speckle Filter. Map-project SLC-derived products with Range-Doppler Terrain Correction.
