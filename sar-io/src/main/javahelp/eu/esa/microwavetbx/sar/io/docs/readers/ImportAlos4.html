Import ALOS-4 PALSAR-3

SNAP has two ALOS-4 readers: ALOS-4 CEOS for products in CEOS format and ALOS-4 GeoTIFF for detected products in GeoTIFF format. Both are under File > Import > SAR Sensors. ALOS (PALSAR) and ALOS-2 products have their own pages: Import ALOS PALSAR and Import ALOS-2.

Mission

  • Operator: JAXA (Japan Aerospace Exploration Agency).
  • Instrument: PALSAR-3, L-band SAR (wavelength about 24 cm). Centre frequency 1257.5 MHz in Spotlight and Stripmap; 1236.5, 1257.5 or 1278.5 MHz in ScanSAR.
  • Orbit: sun-synchronous, 628 km altitude, 14-day repeat cycle.
  • Launch: 1 July 2024 on an H3 rocket from Tanegashima. The satellite is operational.
  • Modes: Spotlight (3 m × 1 m, 35 km swath), Stripmap (3 to 10 m, 100 to 200 km swath) and ScanSAR (25 m, 700 km swath).

How to open

  • CEOS: select the volume file VOL-ALOS4.... The leader file (LED-ALOS4...) and the image files (IMG-HH-..., IMG-HV-...) must be in the same folder; a trailer file (TRL-ALOS4...) is read when present. You can also select a ZIP archive that contains the volume file.
  • GeoTIFF: select one of the image files, for example IMG-HH-ALOS4...tif. The file summary-ALOS4....txt must be in the same folder. All polarisation files in the folder are loaded into one product. Unzip the delivery first.

What you get

  • L1.1 (CEOS): complex bands i_HH and q_HH (units real and imaginary) per polarisation, plus a virtual Intensity_HH band.
  • L1.5 (CEOS) and GeoTIFF: a detected Amplitude_HH band per polarisation, plus a virtual Intensity_HH band.
  • CEOS products carry tie-point grids and the orbit state vectors of the leader file. GeoTIFF products take their map geocoding from the GeoTIFF.
  • The acquisition mode (Spotlight, Stripmap or ScanSAR) and the other mission parameters are in the Abstracted Metadata.

Known limitations

  • The GeoTIFF reader fills only basic metadata. Its orbit is a single approximate state vector, the pass is always set to descending and the radar frequency is fixed at 1236.5 MHz. Use GeoTIFF products for viewing; for calibration, terrain correction, InSAR or polarimetry, order the products in CEOS format.
  • Apply Orbit File has no ALOS-4 orbit type; SNAP uses the orbit in the leader file.
  • The ALOS Deskewing operator is for ALOS (PALSAR) only and is not needed.

Recommended next step

  • L1.5 (CEOS): Radiometric Calibration → Speckle Filter → Range Doppler Terrain Correction.
  • L1.1 for interferometry: Create Stack or DEM Assisted Coregistration → Interferogram. See InSAR concepts.
  • Quad-pol L1.1: Polarimetric Matrices.

Product format specification

JAXA publishes the ALOS-4/PALSAR-3 Standard Product Definition and the CEOS and GeoTIFF Product Format Descriptions on its ALOS-4 data page: https://www.eorc.jaxa.jp/ALOS/en/alos-4/a4_data_e.htm. Mission overview: https://www.eoportal.org/satellite-missions/alos-4.
