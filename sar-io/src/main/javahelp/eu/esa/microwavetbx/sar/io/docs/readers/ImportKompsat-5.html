Import KOMPSAT-5

KOMPSAT-5 (Korea Multi-Purpose Satellite 5) is a Korean X-band SAR satellite. SNAP reads its products with the Kompsat5 reader, in both the HDF5 and the GeoTIFF delivery.

Mission

  • Operator: KARI, the Korea Aerospace Research Institute.
  • Radar: X-band, 9.66 GHz (wavelength about 3.2 cm); HH, HV, VH or VV, one polarisation per acquisition.
  • Orbit: sun-synchronous dawn-dusk orbit at about 550 km, 28-day repeat cycle.
  • Lifetime: launched 22 August 2013; in extended operations.
  • Modes: High Resolution (spotlight, about 1 m, 5 km swath), Standard (stripmap, about 3 m, 30 km swath) and Wide Swath (ScanSAR, about 20 m, 100 km swath).

Supported products

How to open

File names start with K5_. Select one of:

  • the K5_*_Aux.xml metadata file,
  • the K5_*.h5 image (HDF5 delivery) or the K5_*.tif image (GeoTIFF delivery),
  • or the product folder.

When you select the Aux.xml file, the reader uses the .h5 or .tif file in the same folder.

What you get

  • SCS: i_ and q_ bands per polarisation (for example i_HH, q_HH) and a virtual Intensity_HH band.
  • GEC, GTC, WEC, WTC: an Amplitude_ band and a virtual Intensity_ band.
  • Tie-point grids for latitude, longitude, incidence angle and slant-range time.

The mission and acquisition parameters SNAP uses are listed in the Abstracted Metadata.

Known limitations

  • Precise orbits are not downloaded automatically. To use Apply Orbit File, place the Kompsat-5 orbit files in the folder named by the operator's error message.

Recommended next step

Apply Orbit File (if you have precise orbit files), then Calibration. For SCS products continue with Multilook or an InSAR chain; for detected products with Speckle Filter and Terrain Correction.
