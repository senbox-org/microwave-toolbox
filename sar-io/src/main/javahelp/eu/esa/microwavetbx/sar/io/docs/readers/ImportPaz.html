Import PAZ SAR

PAZ is a Spanish X-band SAR satellite. It uses the same product format as TerraSAR-X, and SNAP reads it with the PAZ reader, which shares its code with the TerraSAR-X reader.

Mission

  • Operator: Hisdesat (Spain); INTA runs the ground segment.
  • Radar: X-band, 9.65 GHz (wavelength about 3.1 cm).
  • Orbit: sun-synchronous dawn-dusk orbit at 514 km, 11-day repeat cycle, in the same orbit as TerraSAR-X and TanDEM-X.
  • Lifetime: launched 22 February 2018; in extended operations.
  • Modes: Stripmap, ScanSAR, Spotlight and High Resolution Spotlight.
  • Polarisation: single (HH, VV, HV or VH) or dual.

Supported products

ProductContent
SSCSingle Look Slant Range Complex (COSAR binary image)

How to open

Select the main XML annotation file in the product folder, for example PAZ1_SAR__SSC_*.xml. The file name must start with PAZ and contain _SAR_. Keep the folder structure of the delivery intact.

What you get

  • SSC: i_ and q_ bands per polarisation (for example i_VV) and a virtual Intensity_ band.
  • MGD, GEC, EEC: Amplitude_ bands and virtual Intensity_ bands.
  • Tie-point grids for latitude, longitude, incidence angle and slant-range time.

The mission and acquisition parameters SNAP uses are listed in the Abstracted Metadata.

Known limitations

  • Zipped deliveries are not recognised by name; unzip the product and select the XML file.
  • Apply Orbit File has no PAZ orbit source; the reader uses the orbit in the annotation.

Recommended next step

Calibration, then Speckle Filter and Range-Doppler Terrain Correction for detected products. For SSC pairs, see Create Stack and Interferogram Formation.
