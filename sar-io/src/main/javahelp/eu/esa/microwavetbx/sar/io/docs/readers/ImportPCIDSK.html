Import PCIDSK

PCIDSK (.pix) is the native raster database format of the PCI Geomatics software. It is a generic raster format, not a SAR mission format.

Format

A PCIDSK file holds one or more image channels together with their georeferencing in a single .pix file.

Supported data

SNAP opens .pix files with its GDAL reader for the PCIDSK format ("PCIDSK Database File"). The Microwave Toolbox has an older built-in PCIDSK reader, but it is no longer registered, so it is not used. The Microwave Toolbox menu entry for PCIDSK is also disabled.

How to open

Use File > Open Product and select the .pix file. SNAP picks the GDAL PCIDSK reader automatically.

What you get

  • One band per PCIDSK channel. A band takes the channel description as its name; channels without a description are named band_1, band_2, ...
  • The map projection stored in the file is used for geocoding.
  • No SAR metadata: the product has no Abstracted Metadata with orbit, timing or radar parameters.

Known limitations

Because the SAR metadata is missing, operators that need it, such as Calibration, Apply Orbit File or Range-Doppler Terrain Correction, cannot be used on a PCIDSK product. Use the original mission product for SAR processing, and PCIDSK only for map-projected results.

Recommended next step

Display the bands, or combine them with Band Maths. For SAR processing, open the original mission product instead; see Supported Missions.

Product format specification

SNAP reads PCIDSK through GDAL; the GDAL driver page describes what is supported: https://gdal.org/en/stable/drivers/raster/pcidsk.html.
