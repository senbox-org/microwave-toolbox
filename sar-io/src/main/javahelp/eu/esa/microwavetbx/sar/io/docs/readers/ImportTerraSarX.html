Import TerraSAR-X / TanDEM-X

TerraSAR-X and TanDEM-X are two nearly identical German X-band SAR satellites flying in close formation. SNAP reads their products, including the TanDEM-X CoSSC products, with the TerraSarX reader. PAZ products use the same format; see PAZ.

Mission

  • Operator: DLR, which also holds the science data rights; Airbus holds the commercial rights.
  • Radar: X-band, 9.65 GHz (wavelength about 3.1 cm).
  • Orbit: sun-synchronous dawn-dusk orbit at about 515 km, 11-day repeat cycle.
  • Lifetime: TerraSAR-X launched 15 June 2007; TanDEM-X launched 21 June 2010. Both are in extended operations.
  • Formation: TanDEM-X flies a few hundred metres from TerraSAR-X. In bistatic mode one satellite transmits and both receive, giving single-pass interferometry; this produced the global TanDEM-X DEM.
  • Modes: Stripmap, ScanSAR, Wide ScanSAR, Spotlight, High Resolution Spotlight and Staring Spotlight.
  • Polarisation: single, dual and quad.

How to open

Select the main XML annotation file in the product folder. Its name starts with TSX1, TSX2, TDX1, TDX2, TDM1 or TDM2, for example TSX1_SAR__SSC_*.xml or TDM1_SAR__COS_*.xml. Keep the folder structure of the delivery intact. Unzip zipped deliveries first.

What you get

  • SSC: i_/q_ bands per polarisation (for example i_HH) and virtual Intensity_ bands.
  • CoSSC: one complex pair per satellite. Bands carry the stack suffixes _ref (Reference) and _sec1 (Secondary) plus the acquisition date, so the product is a ready-made two-image stack.
  • MGD, GEC, EEC: Amplitude_ bands and virtual Intensity_ bands.
  • Tie-point grids for latitude, longitude, incidence angle and slant-range time.

The mission and acquisition parameters SNAP uses are listed in the Abstracted Metadata.

Known limitations

  • Apply Orbit File has no TerraSAR-X source; the reader uses the orbit in the annotation.

Recommended next step

Calibration, then Speckle Filter and Range-Doppler Terrain Correction for detected products. For a CoSSC pair go straight to Interferogram Formation; for repeat-pass SSC pairs use Create Stack first.

Product format specification
