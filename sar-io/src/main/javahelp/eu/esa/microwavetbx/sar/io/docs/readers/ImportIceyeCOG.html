Import ICEYE COG

The ICEYE COG reader (File > Import > SAR Sensors > ICEYE COG) opens ICEYE products delivered as Cloud-Optimized GeoTIFF (COG), including products from the ICEYE Open Data programme. Legacy HDF5 deliveries use Import ICEYE.

Mission

  • Operator: ICEYE (Finland), a commercial constellation of X-band SAR microsatellites.
  • Instrument: X-band SAR near 9.65 GHz (wavelength about 3.1 cm), VV polarisation.
  • Orbit: mostly sun-synchronous low Earth orbits, roughly 500–610 km altitude, plus some mid-inclination orbits.
  • Launch: the first satellite, ICEYE-X1, was launched on 12 January 2018. Many more have been launched since.

Supported products

ProductContent
SLC (COG)Single-look complex, slant range, stored as amplitude and phase
GRD (COG)Detected, ground range
Open Data SLC-COG and GRD-COGSame content, with a STAC item as sidecar
GeoTIFF GRDDetected image whose TIFF tags carry the ICEYE metadata

Imaging modes: Spot, Strip, Scan and Dwell (and their variants). Polarisation: VV.

How to open

Select the image ICEYE_....tif, or its sidecar ICEYE_....json or ICEYE_....xml when the .tif with the same name lies beside it. All open the same product. The reader identifies the delivery from the metadata stored inside the GeoTIFF, so the sidecar file is not required.

What you get

  • SLC: Amplitude_VV and Phase_VV bands, plus virtual i_VV, q_VV (units real and imaginary) and Intensity_VV bands, so SAR operators see a complex product.
  • GRD: Amplitude_VV plus a virtual Intensity_VV.
  • Orientation: ICEYE writes these files "shadows-down", with azimuth along the image columns. SNAP turns them into its own SAR convention (x across range, y along azimuth), so the raster is the transpose of what a plain GeoTIFF viewer shows.
  • Tie-point grids, orbit state vectors and acquisition parameters in the Abstracted Metadata.

Known limitations

  • Opening the file with a generic GeoTIFF reader instead bypasses the transpose and the SAR metadata; the result cannot be used by the SAR operators.
  • Products are read from local files; select a downloaded copy.
