Polarimetric Parameters

Polarimetric Parameters Operator

Computes a configurable bank of general-purpose polarimetric scalar parameters and channel-algebra outputs from a quad-pol, dual-pol or compact-pol SAR product. Span, Pedestal Height and the complex-input RVI are computed from the coherency matrix T3, averaged in a sliding window when Use Mean Matrix is on. All other outputs are computed pixel by pixel from the input.

Input modes (auto-detected)

  • Intensity bands — the source product carries intensity bands (_HH, _HV, _VV, _VH), for example the Intensity bands of an SLC or a detected dual-pol (GRD) or quad-pol product. The channel ratios and indices are computed from those bands. When intensity bands are present they are always used, so on an SLC the Coh_ and Phase_ outputs are refused.
  • Matrix elements — the source is a C2, C3 or T3 product from Polarimetric Matrix Generation (or the speckle filter). Diagonal elements give the channel powers; off-diagonal elements give the complex correlations used for the Phase and Coherence outputs.

The C2 band names do not say which two channels the product holds. The operator reads the pair from the polarisation metadata that Matrix Generation copies (HH+HV, VV+VH or HH+VV); a Sentinel-1 VV+VH C2 gives VVVHRatio, Coh_VVVH and Phase_VVVH. Without that metadata (and for compact-pol C2) the pair is treated as HH and VV. Outputs that need a missing channel are rejected at validation.

On a coregistered stack each date gets its own output bands, named with the date suffix.

Available outputs

All channel values are linear power (intensity, for example σ0), not amplitude and not dB.

  • Span — total power, the trace of T3: |SHH|2 + 2|SHV|2 + |SVV|2. Requires a complex C3/T3/FULL input. Unit intensity.
  • Pedestal Height — λ3/λ1, the smallest over the largest eigenvalue of T3; a measure of the depolarised (random) part of the return. Requires a complex C3/T3/FULL input. Dimensionless.
  • Radar Vegetation Index (RVI) — requires quad-pol input, in one of two forms. On complex input (SLC, C3, T3) it is the eigenvalue form 4λ3 / (λ1 + λ2 + λ3) of T3. On detected quad-pol intensities it is the Kim and van Zyl (2009) form 8σHV / (σHH + σVV + 2σHV). Both are 0 for a pure surface and 1 for a cloud of random dipoles, but they differ in between, so do not mix them. Dimensionless.
  • Radar Forest Degradation Index (RFDI) — (HH−HV) / (HH+HV) (Mitchard et al. 2012). Dimensionless.
  • Canopy Structure Index (CSI) = VV/(VV+HH), Volume Scattering Index (VSI) = (HV+VH)/(HH+VV+HV+VH), Biomass Index (BMI) = (HH+VV)/2 and Interaction Index (ITI) = HH/VV, from Pope et al. (1994). BMI is a power (unit intensity); the others are dimensionless. ITI and the HH/VV ratio are the same quantity by definition; both bands are kept.
  • Ratios: HH/VV, HH/HV, VV/VH. Dimensionless.
  • Complex Correlation (matrix input only) — |cij| / √(cii·cjj) between channel pairs, in [0, 1]. Output bands: Coh_HHVV, Coh_HHHV, Coh_VVVH as available per input mode. Unit coherence.
  • Off-diagonal Phase (matrix input only) — arg(cij) in radians. Output bands: Phase_HHVV = arg<SHHSVV*>, Phase_HHHV = arg<SHHSHV*> and Phase_VVVH = arg<SVVSVH*> (the same order for quad-pol and dual-pol input), as available per input mode. Unit phase.

Notes on Phase and Coherence outputs

  • They are computed from the input matrix of each pixel; the window is not applied. On a single-look matrix every Coh_ band is 1 and the phases are noise, so run the Polarimetric Speckle Filter first.
  • For C3 / T3 / FULL input these are the C3 lex-basis correlations — T3 input is converted to C3 internally so the user always sees HH/HV/VV-named outputs regardless of whether the matrix product was generated as T or C. HV stands for (SHV + SVH)/2.
  • The C3 c22 element stores 2|HV|2, so the HV power and HV-paired correlations are normalised by the √2 basis factor before being written.
  • For C2 dual-pol input only one phase/coherence is meaningful (between the two channels actually present); the corresponding Phase_/Coh_ band carries that pair.

Changed in SNAP 15. Span is now the trace of T3 (half the earlier value); RVI on complex input now follows the eigenvalue formula above (earlier values were wrong); the ratios and indices use power instead of amplitude (the ratios are the squares of the earlier values); quad-pol Phase_VVVH changed sign; and a Sentinel-1 C2 product gets VV/VH bands instead of HH/VV bands. Do not compare these outputs with results from earlier SNAP versions.

Parameters

  • Use Mean Matrix — when true, Span, Pedestal Height and the complex-input RVI are computed on the coherency matrix averaged over the window (recommended). When false, they are computed on the per-pixel single-look matrix (noisier). The other outputs are always per pixel.
  • Window Size X / Y — sliding window for the mean matrix. Default 5×5.
  • Output flags — one boolean per output band.

Prerequisites

  • Polarimetric SAR product containing the channels that the selected outputs need (for example HH and HV for RFDI, all four channels for VSI); a missing channel stops the operator
  • Quad-pol C3/T3/scattering-matrix input for Span, Pedestal Height and RVI; Span and Pedestal Height also need complex (SLC-derived) data
