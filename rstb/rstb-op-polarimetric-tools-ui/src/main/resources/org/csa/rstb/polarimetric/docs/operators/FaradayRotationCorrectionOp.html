Faraday Rotation Correction

Faraday Rotation Correction Operator

Removes the ionospheric Faraday-rotation signature from a quad-polarimetric SAR product. As the radar wave traverses the ionosphere, the plane of polarization rotates by an angle Ω that depends on the total electron content (TEC), the geomagnetic field component along the line of sight, and the radar wavelength (Ω ∝ λ2). At L-band and longer this can be tens of degrees and badly distorts the measured polarimetric quantities; at C-band and X-band the effect is small and usually negligible.

For a quad-pol product the observed and true scattering matrices are related by:

Sobs = R(Ω) · Strue · R(Ω)

where R(Ω) = [cosΩ, sinΩ; −sinΩ, cosΩ] is the 2×2 rotation matrix. This operator estimates Ω from the observed scattering matrix with the Bickel-Bates estimator [1, 2], which works in the circular-polarisation basis. It first forms the two circular cross-pol terms

Z12 = SHV − SVH + j·(SHH + SVV)
Z21 = SVH − SHV + j·(SHH + SVV)

for every pixel, averages their product Z12·Z21* over the sliding window (<·>), and takes

Ω = −(1/4) · arg( <Z12 · Z21*> )

where * is the complex conjugate. The minus sign belongs to the rotation-matrix convention above: with it, a simple surface-like target (SHH = SVV, no cross-pol) rotated by Ω gives back exactly Ω. The operator then applies the inverse rotation, Strue = R(−Ω) · Sobs · R(−Ω), to the centre pixel. Because arg() returns a value in (−π, π], the estimate is unambiguous only for |Ω| < 45°.

Input

Full quad-pol SLC product with the complex scattering matrix (i/q bands for HH, HV, VH, VV). The operator rejects dual-pol and compact-pol inputs and C3/T3 matrix products.

Output

A quad-pol product with the same i/q bands, with the Faraday rotation removed. The estimated angle Ω is not written to the output.

Parameters

  • Window Size — size of the sliding window over which Z12·Z21* is averaged before computing Ω. Default 10 (range 1–100). The window extends Window Size / 2 pixels (rounded down) each side of the centre pixel, so the default uses 11 × 11 pixels. Larger windows give a less noisy Ω at the cost of resolution.

Notes

  • The correction is most relevant for L-band (ALOS-1/2/4, SAOCOM, NISAR) and P-band (BIOMASS) data. Applying it to C-band or X-band is harmless but usually has negligible effect.
  • The Bickel-Bates estimator assumes reciprocity (SHV = SVH) of the true scattering matrix. Residual cross-talk, channel imbalance and noise bias the estimate, so system distortions are removed first.
  • Processing order. Run this operator on the scattering matrix after radiometric Calibration (complex output) and, if used, Polarimetric Calibration, and before Cross-Channel SNR Correction. Faraday rotation itself decorrelates HV and VH: Ω = 2° already lowers the HV–VH coherence to about 0.8, and 5° to about 0.2. An SNR correction run first would treat that decorrelation as noise and cut HV (by about 1 dB at Ω = 2°).
