Polarimetric Calibration (Quegan / Ainsworth)

Read this before running the operator

This operator is experimental. Its options are named after Quegan (1994) and Ainsworth et al. (2006), but it implements a simplified form: a Quegan-type cross-talk solve, repeated for Ainsworth, not the full Ainsworth et al. fit. By default it estimates and removes only the cross-talk and leaves the co-polar channel imbalance untouched (f = 1), so the HH/VV ratio of the data is kept. An option estimates the co-polar imbalance from the scene, but that estimate assumes equal HH and VV power and forces VV/HH to 0 dB. Check the output against corner reflectors or a reference processor before you use it.

It is not radiometric calibration. The standard Calibration operator scales the pixel values to σ0, γ0 or β0 with the product's calibration LUT, and every workflow needs it. Polarimetric calibration addresses a different problem: leakage and gain differences between the polarisation channels of the scattering matrix. Most polarimetric workflows do not need it, and running it on data that are already polarimetrically calibrated can only make them worse.

What this operator does

  • Cross-talk. It forms the 4×4 covariance of the scattering vector [HH, HV, VH, VV] over the whole scene (sub-sampled) and estimates the four cross-talk terms δ1..4 from two 2×2 linear systems built from the correlations of HV and VH with HH and VV, in the form of Quegan (1994). The solve assumes reflection symmetry (co- and cross-polar channels uncorrelated).
  • Channel imbalance: left untouched by default. The model has one complex co-polar imbalance f, which scales HV and VH by f and VV by f2. Quegan (1994) and Ainsworth et al. (2006) both state that |f| cannot be estimated from distributed targets; it needs a target with a known HH/VV ratio and phase, such as a trihedral corner reflector. By default the operator therefore keeps f = 1: the cross-talk solve still removes the cross-talk, and any co-polar imbalance in the data, together with the scene's true HH/VV ratio, passes through unchanged.
  • Optional scene estimate of f. With Estimate co-pol channel imbalance from the scene switched on, the operator estimates |f| = (<|VV|2> / <|HH|2>)1/4 and arg f = −arg<HH·VV*> / 2 and removes it. This assumes that the scene-average HH and VV powers are equal and that the HH–VV phase is zero, and the correction forces the scene to meet it: the output VV/HH ratio is 0 dB whatever the true ratio was. Natural scenes rarely meet this (bare soil and water have VV above HH), so the option is normally only valid when the statistics reflect a trihedral-based estimate. The phase of f is found only up to π: if the true one-way imbalance phase is beyond ±90°, VV is still corrected but HV and VH come out with inverted sign. For a true co-polar imbalance, measure it on a corner reflector; the operator does not yet accept such a measurement as input.
  • No cross-polar imbalance. The model uses the same f on transmit and receive, so a gain difference between HV and VH is not estimated.
  • It then applies the inverse 4×4 distortion matrix (cross-talk, plus the imbalance if the option is on), the same for every pixel.

The output is a scattering-matrix product with the same 8 bands (i/q for HH, HV, VH, VV).

The two methods

Both methods run the same estimate; method changes only how often it runs.

  • Quegan: one pass.
  • Ainsworth (default): Ainsworth Iterations passes (default 4). Each pass corrects the original covariance with the estimate so far and adds the remaining residual to the estimate, so the passes converge to the distortion that leaves no correlation between the co- and cross-polar channels.

In synthetic tests of this code (a reflection-symmetric scene, −25 dB cross-talk and a known imbalance):

  • With the default settings both methods removed the co/cross-polar correlation (below 0.02) and left the VV/HH ratio as it was. A scene with no distortion and a true VV/HH of +6 dB kept +6 dB.
  • With the scene estimate switched on and a scene that has equal HH and VV power, both methods recovered the imbalance to within 0.02 and each cross-talk term to within 15 %.

One pass leaves a first-order error of a few per cent in each cross-talk term, which the further passes remove.

Changed in SNAP 15: the cross-talk estimator was rewritten. The repeated passes of earlier versions could add cross-talk instead of removing it, so results differ from earlier versions. As in earlier versions, the co-polar imbalance is not applied by default (channelImbalance 1 + 0j); the scene estimate is a new, opt-in parameter.

When to run it, and when not to

Your dataRun it?
Quad-pol product from an operational spaceborne mission (for example RADARSAT-2, ALOS-2, SAOCOM). These are normally delivered polarimetrically calibrated; check the product documentation. No. Use Calibration only.
Dual-pol, compact-pol or single-pol product (for example all Sentinel-1 products) Not possible. The operator accepts only a quad-pol scattering matrix.
C3, C4, T3 or T4 matrix product Not possible. Run it on the scattering matrix, before Polarimetric Matrix Generation.
You need a calibrated co-polar channel balance (HH/VV ratio and phase) No. By default the operator leaves the HH/VV ratio untouched, and its optional scene estimate forces the scene-average HH/VV ratio to 1 (0 dB) and the HH–VV phase to 0; use corner reflectors and the provider's calibration.
Quad-pol data whose documentation states that cross-talk has not been corrected, for example some airborne research data Only as an experiment. Compare the result with corner reflectors or a reference processor (for example PolSARpro) before using it. If you switch on the co-polar imbalance estimate, check the HH/VV balance it applied.
L- or P-band data with Faraday rotation Use with care. Part of any Faraday rotation is absorbed into the cross-talk estimate.

Inputs

  • Full quad-pol scattering matrix product (FULL): 8 bands — i/q components of SHH, SHV, SVH, SVV. Other product types are rejected.

Parameters

  • Calibration method: Quegan (one pass) or Ainsworth (repeated passes, default). See The two methods above.
  • Ainsworth Iterations: number of passes for Ainsworth (default 4, range 1–50). Ignored for Quegan. Later passes refine the estimate; a few are enough.
  • Estimate co-pol channel imbalance from the scene (estimateCoPolImbalance, default off): estimate the co-polar imbalance f from the scene and remove it. This assumes <|HH|2> = <|VV|2> over the scene and forces VV/HH to 0 dB; it is normally only valid with a trihedral-based estimate. Off: f = 1, only the cross-talk is corrected.
  • Stats Sub-sampling: only every Nth pixel in row and column is used for the scene covariance. The default 10 uses 1 pixel in 100.
  • Save Distortion to Metadata: writes the estimates to the element Polarimetric_Calibration of the abstracted metadata (default on).

Outputs

  • Scattering matrix with the cross-talk correction (and, if the option is on, the channel-imbalance correction) applied, in the same FULL band layout as the input.
  • (Optional) metadata element Polarimetric_Calibration: method, channelImbalance_re/_im (the one-way imbalance f that was applied: 1 and 0 by default, meaning no co-polar correction; with the scene estimate on, the estimated f, and the VV/HH amplitude ratio it removed is |f|2) and delta1...delta4 (_re/_im). The metadata numbering of delta1...delta4 differs from the δ1...δ4 of the distortion model on the concept page.

References

The cross-talk solve has the form of Quegan (1994); the Ainsworth option repeats it and does not implement the published Ainsworth et al. (2006) algorithm:

  1. Quegan, S. (1994). A unified algorithm for phase and cross-talk calibration of polarimetric data — theory and observations. IEEE Transactions on Geoscience and Remote Sensing, 32(1), 89–99. doi:10.1109/36.285192
  2. Ainsworth, T. L., Ferro-Famil, L., Lee, J.-S. (2006). Orientation angle preserving a posteriori polarimetric SAR calibration. IEEE Transactions on Geoscience and Remote Sensing, 44(4), 994–1003. doi:10.1109/TGRS.2005.862508
