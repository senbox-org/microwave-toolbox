Compact Polarimetric Decomposition Operator

  • m-chi decomposition
  • m-delta decomposition
  • m-alpha decomposition
  • H-Alpha decomposition
  • 2-layer RVOG decomposition
  • Model-Free 3-Component Decomposition (MF3CC)

Three RGB power components computed from the Stokes vector and degree of polarization m:

Pd = m · g0 · sin2(αs)  (Red, double-bounce)
Pv = (1 − m) · g0  (Green, volume)
Ps = m · g0 · cos2(αs)  (Blue, surface)

where αs = ½ · atan2(√(g12+g22), ±g3) is the compact-pol alpha angle (sign depending on RCH/LCH mode).

Input and Output

  • The input to this operator should be a simulated compact polarimetric SAR product in complex scattering vector or complex covariance matrix format.
  • The output of this operator is the m-chi, m-delta, m-alpha, H-Alpha, RVOG or model-free 3-component decomposition result represented by RGB colours.

Parameters Used

   The following processing parameters are needed (see Figure 1):
  • Decomposition: m-chi, m-delta, m-alpha, H-Alpha, RVOG decomposition or Model-Free 3-Component Decomposition
  • Window Size X: X dimension of the sliding window used in computing the mean covariance matrix
  • Window Size Y: Y dimension of the sliding window used in computing the mean covariance matrix
