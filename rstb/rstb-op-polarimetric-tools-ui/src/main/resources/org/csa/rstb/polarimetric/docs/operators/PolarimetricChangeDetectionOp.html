Polarimetric Change Detection (P-CCD / GLRT)

Generalized Likelihood Ratio Test on Polarimetric Covariance Matrices

Detects change between two coregistered polarimetric SAR products by testing the null hypothesis "the two complex Wishart-distributed covariance/coherency matrices are equal" via a generalized likelihood ratio test [1].

For two p×p Hermitian matrices C1, C2 averaged over N looks each:

    ln Q = N · ln |C1| + N · ln |C2| − 2N · ln |(C1 + C2) / 2|
    T    = −2 · ln Q

Under the null hypothesis, T is asymptotically χ2 distributed with p2 degrees of freedom (4 for C2 dual-pol, 9 for T3/C3 quad-pol). The change probability is:

    p_change = Fχ2(p2)(T)

Inputs

  • Reference: a polarimetric C2/C3/T3 covariance/coherency matrix product.
  • Secondary: a coregistered polarimetric product of the same matrix type and dimensions.

Parameters

  • Window Size: square sliding window used to average each input matrix before the test. Values 3, 5, 7, 9, 11, 13, 15; default 5.
  • Number of Looks (ENL): the N in the formula above. Range 1–10000; default 5. The operator uses this value as it is; it does not add the looks gained from the window.
  • Significance Level α: false-alarm rate for the binary change mask. Pixel is flagged as changed when p_change ≥ 1−α. Range 0–1; default 0.0001.
  • Output Test Statistic, Output Change Probability, Output Change Mask: choose which of the three output bands to write. All are on by default.

Choosing the Number of Looks

N must be the number of looks of the matrices that are actually compared, that is, after the window averaging. Averaging over the window raises the effective number of looks to about (ENL of the input) × (number of independent pixels in the window). For example, an SLC (ENL ≈ 1) with the default 5 × 5 window has up to about 25 looks, not 1. Setting N to the input ENL alone makes T, and therefore the change probability, too small, so real changes are missed.

In practice, set N to the input ENL times Window Size2, and reduce it somewhat when neighbouring pixels are correlated (oversampled SLCs, or products already speckle-filtered or multilooked). If you know the ENL of the averaged matrices (for example, estimated over a homogeneous area), use that value.

Outputs

  • TestStatistic: T = −2·ln Q.
  • ChangeProbability: p_change ∈ [0, 1] via the Wilson–Hilferty χ2 CDF approximation.
  • ChangeMask: binary 0/1 mask, 1 = changed at the chosen significance level.

Reference
