Cross-Channel SNR Correction

Cross-Channel SNR Correction Operator

Estimates and removes the cross-channel noise floor in a quad-polarimetric SAR product by exploiting the reciprocity assumption SHV = SVH. For an ideal monostatic radar this equality holds, so once Faraday rotation has been removed, decorrelation between the HV and VH channels is taken to be additive noise. The operator uses the local HV-VH coherence inside a sliding window as a measure of the channel SNR and scales the cross-pol channels down to suppress that noise contribution.

Algorithm (sketch)

Inside each window the operator computes the sample HV-VH coherence:

γcross = | E[SHV · conj(SVH)] | / sqrt(E[|SHV|2] · E[|SVH|2])

It then multiplies the HV and VH values (i and q) by √γcross, so their power is scaled by γcross. HH and VV are not changed.

If HV and VH carry the same signal power and independent noise of equal power, then γcross = P / (P + N), where P is the signal and N the noise power, so on average the corrected power equals the signal power P. Anything else that lowers γcross (residual cross-talk, Faraday rotation) is removed as if it were noise.

Changed in SNAP 15: earlier versions multiplied by γcross itself, so their HV and VH power was lower by a further factor γcross (−3 dB at an SNR of 0 dB).

Faraday rotation also decorrelates HV and VH, so run Faraday Rotation Correction first where it is needed.

Input

Full quad-pol SLC product. The operator rejects compact-pol or dual-pol inputs.

Output

A new quad-pol product mirroring the input structure, with the HV / VH channels SNR-corrected. The HH and VV channels pass through unchanged.

Parameters

  • Window Size — sliding window size used for the coherence estimate (default 5; range 1–100). Larger windows reduce variance of the coherence estimate at the cost of spatial resolution.
