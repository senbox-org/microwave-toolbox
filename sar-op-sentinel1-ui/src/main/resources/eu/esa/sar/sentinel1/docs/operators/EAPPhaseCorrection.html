EAP Phase Correction

Elevation Antenna Pattern Phase Correction

The Elevation Antenna Patterns (EAPs) used by the S-1 Instrument Processing Facility (IPF) are derived from the S-1 Antenna Model (AM) which is able to predict with great accuracy the gain and phase patterns.

The EAP correction by the S-1 IPF was at launch only considering the gain of the EAP. Similarly to what was done for ASAR. As an outcome of the S-1A Commissioning Phase, it has been decided to upgrade the S-1 IPF to also correct for the EAP phase, in order to correct for the induced phase difference between the polarimetric channels.

This correction has been introduced in March 2015 with the IPF V243. Performing interferograms between products generated with the IPFV243 and the former version V236 leads to phase offset.

This operator performs EAP corrections for products generated before March 2015 [1].

Background

Prerequisites

  • Sentinel-1 SLC product with processor IPF version below 2.43; newer products are rejected as already corrected.
  • Complex products must have I and Q bands in pairs with units.
  • A matching AUX_CAL file must be found.
