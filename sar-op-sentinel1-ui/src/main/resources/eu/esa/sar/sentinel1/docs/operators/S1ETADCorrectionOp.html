ETAD Correction for Sentinel-1 Products

The operator applies the ETAD correction to Sentinel-1 TOPS SLC, Stripmap and GRD products. The Extended Timing Annotation Dataset (ETAD) for Copernicus Sentinel-1 is a new auxiliary product developed by ESA in a joint effort with DLR. It estimates the errors caused by the geophysical effects during imaging and the errors introduced during the processing of the Sentinel-1 SLC product. With the application of the ETAD correction, the geometric accuracy of the Sentinel-1 SLC images could be improved to centimetric levels. 

The operator offers two corrections, which correspond to the two checkboxes in the UI (Figure 1) below. Resample image (geometric correction) computes for all pixels the range and azimuth offsets based on the user selected ETAD correction layers, then resamples the image based on the computed range and azimuth offsets. It is for applications where accurate geodetic geolocation is required. Apply range-delay phase correction is for InSAR applications where the interferogram is generated from ETAD corrected Sentinel-1 SLC products. Either one or both can be selected, see below. 

For TOPS SLC product, the operator currently requires the users split the product into sub-swathes and applies the ETAD correction to each split product. 

Input

  • The input to this operator could be the split Sentinel-1 TOPS SLC product, Stripmap SLC product or GRD product.

Output

  • The output of the operator is the ETAD corrected product.

Parameters Used

  • Auto-download ETAD File: If selected, the operator will find the corresponding ETAD product for the source product and download it automatically from the Copernicus Data Space.
  • Specify ETAD File: In case the ETAD file is not available and cannot be downloaded automatically, users can use their ETAD product obtained from other sources with this option.
  • Resample image (geometric correction): On by default. The operator computes the range and azimuth offsets of every pixel from the selected ETAD correction layers and resamples the image accordingly. Use it when accurate geolocation is required. At least one correction layer must be selected, otherwise the operator stops with "No correction layer is selected".
  • Resampling Type: The interpolation method used for resampling the image (default: BISINC_5_POINT_INTERPOLATION). Only available when Resample image is selected.
  • ETAD Correction Layers: The range and azimuth correction layers available for ETAD correction. Users can select the layers that matter to their applications. Note that the "Sum Of Range Corrections" layer contains all the individual range correction layers in it, and the "Sum Of Azimuth Corrections" contains all the individual azimuth correction layers. Therefore, they should not be selected together with any of the individual layers. By default both sum layers are selected. The layers apply only when Resample image is selected.
  • Apply range-delay phase correction (outputPhaseCorrections in GPT and graph XML): Off by default. The range corrections are converted to a phase correction. It works for Sentinel-1 IW SLC and SM SLC products only. If Resample image is not selected, the phase correction is saved as tie-point grids in the output product and is used later by the Interferogram operator to correct the interferometric phase (classical InSAR chain).
  • Also output the applied phase as a band (diagnostic): Off by default, and available only together with the phase correction. Writes the applied phase as an etadPhase band so that the size of the correction can be checked. This band is not complex, so it changes what coregistration and stacking see.
  • Source Band (sourceBands): Optional list of bands to correct, when set on the command line or in a graph.

The two checkboxes Resample image and Apply range-delay phase correction are independent, not alternatives, and at least one of them must be on. Selecting both applies the geometric correction and removes the range-delay phase from the complex data in one pass. This is the combination needed for the geocode-first (GSLC) InSAR chain, because both corrections then live in the pixels and survive geocoding. The combination is implemented for IW (TOPS) products only; for other modes the operator stops with an explanatory message.

Background

  • Orbits and timing corrections (ETAD, EAP)
  • Sentinel-1 TOPS: bursts, deramping and ESD
  • Workflow: GSLC
  • Atmospheric and Ionospheric Phase

Prerequisites

  • Sentinel-1 product and a matching ETAD product: either a supplied ETAD file or an automatic search.
  • The phase-correction output requires an IW or SM SLC product; combining it with image resampling requires IW.
  • At least one correction layer must be selected when resampling.
